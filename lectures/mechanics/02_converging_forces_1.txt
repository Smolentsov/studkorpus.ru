ЛЕКЦИЯ № 2
Тема: Плоская система сходящихся сил: сложение

Цель лекции: Сформировать представления о плоской системе сходящихся сил, способах сложения двух сил (геометрический и аналитический), а также о проекции силы на ось и определении равнодействующей системы сходящихся сил.

1. ПОНЯТИЕ ПЛОСКОЙ СИСТЕМЫ СХОДЯЩИХСЯ СИЛ
Система сходящихся сил — это система сил, линии действия которых пересекаются в одной точке.
Если все силы лежат в одной плоскости, то система называется плоской системой сходящихся сил.
Для равновесия системы сходящихся сил необходимо и достаточно, чтобы равнодействующая этой системы была равна нулю.

2. СЛОЖЕНИЕ ДВУХ СИЛ (ГЕОМЕТРИЧЕСКИЙ СПОСОБ)
Сложение двух сил, приложенных в одной точке, выполняется по правилу параллелограмма (или треугольника) — это следствие третьей аксиомы статики.
Правило параллелограмма:
Если две силы F1 и F2 приложены в одной точке и образуют угол α, то их равнодействующая R равна диагонали параллелограмма, построенного на этих силах как на сторонах, и направлена по этой диагонали.
Модуль равнодействующей определяется по теореме косинусов:
R = √(F1² + F2² + 2*F1*F2*cos(α)),
где α — угол между векторами сил.
Частные случаи:
1. Если силы направлены в одну сторону (α = 0°), то R = F1 + F2 (равнодействующая максимальна).
2. Если силы направлены в противоположные стороны (α = 180°), то R = |F1 - F2| (равнодействующая минимальна).
3. Если силы перпендикулярны (α = 90°), то R = √(F1² + F2²) (теорема Пифагора).
Правило треугольника:
Из конца вектора F1 проводят вектор F2. Тогда равнодействующая R — это вектор, проведенный из начала F1 в конец F2. Этот способ удобен при построении силового многоугольника для нескольких сил.

3. РАЗЛОЖЕНИЕ СИЛЫ НА ДВЕ СОСТАВЛЯЮЩИЕ
Разложение силы на две составляющие — это обратная задача сложению. Силу F можно разложить на две составляющие F1 и F2, если известны направления этих составляющих (например, вдоль осей X и Y).
Разложение силы на две взаимно перпендикулярные оси:
F_x = F * cos(α),
F_y = F * sin(α),
где α — угол между направлением силы F и осью X.
При этом модуль силы связан с проекциями:
F = √(F_x² + F_y²).

4. СИЛОВОЙ МНОГОУГОЛЬНИК
Для сложения нескольких сил (более двух), приложенных в одной точке, используется правило силового многоугольника.
Порядок построения:
1. Выбирают масштаб (например, 1 кН = 1 см).
2. Из произвольной точки откладывают вектор первой силы.
3. Из конца первой силы откладывают вектор второй силы (параллельно самой себе).
4. Из конца второй силы откладывают вектор третьей силы и т. д.
5. Замыкающая сторона многоугольника (вектор, проведенный из начала первой силы в конец последней) является равнодействующей R.
Если силовой многоугольник замкнут (начало первой силы совпадает с концом последней), то система сил уравновешена (равнодействующая равна нулю). Это графическое условие равновесия системы сходящихся сил.

5. ПРОЕКЦИЯ СИЛЫ НА ОСЬ
Проекция силы на ось — это алгебраическая величина, равная произведению модуля силы на косинус угла между вектором силы и положительным направлением оси.
F_x = F * cos(α),
где α — угол между вектором силы и осью X.
Правило знаков:
- Если проекция направлена в сторону положительного направления оси, она положительна (+).
- Если проекция направлена в противоположную сторону, она отрицательна (-).
- Если сила перпендикулярна оси (α = 90°), проекция равна нулю.

6. АНАЛИТИЧЕСКОЕ ОПРЕДЕЛЕНИЕ РАВНОДЕЙСТВУЮЩЕЙ
Равнодействующая плоской системы сходящихся сил может быть найдена аналитически через проекции на оси X и Y.
Порядок расчета:
1. Выбирают систему координат (оси X и Y).
2. Каждую силу раскладывают на проекции: F_x = F * cos(α), F_y = F * sin(α).
3. Суммируют проекции всех сил на каждую ось:
   R_x = ΣF_x = F1x + F2x + ... + Fnx,
   R_y = ΣF_y = F1y + F2y + ... + Fny.
4. Модуль равнодействующей: R = √(R_x² + R_y²).
5. Направление равнодействующей: tg(φ) = R_y / R_x, где φ — угол между равнодействующей и осью X.
Условие равновесия системы сходящихся сил в аналитической форме:
ΣF_x = 0,
ΣF_y = 0.
То есть сумма проекций всех сил на каждую ось должна быть равна нулю. Это основное уравнение для решения задач на равновесие системы сходящихся сил.

7. РАЦИОНАЛЬНЫЙ ВЫБОР КООРДИНАТНЫХ ОСЕЙ
При решении задач на равновесие системы сходящихся сил важно правильно выбрать направление осей X и Y. Это позволяет упростить уравнения равновесия и уменьшить количество неизвестных.
Рекомендации:
1. Одну из осей (например, X) направляют вдоль линии действия неизвестной реакции связи или вдоль стержня, чтобы проекция этой силы на другую ось была равна нулю.
2. Если в системе есть наклонные силы, оси выбирают так, чтобы одна из сил совпадала с осью (тогда ее проекция на другую ось равна нулю).
3. Если все силы направлены вдоль одной прямой (система коллинеарных сил), достаточно одного уравнения равновесия (ΣF_x = 0).
