Лабораторная работа № 2
Испытание на сжатие образцов из пластичной стали и хрупкой древесины

Цель работы
1. Изучить поведение различных материалов (пластичной стали и хрупкой древесины) при сжатии.
2. Построить диаграммы сжатия для обоих материалов.
3. Сравнить характер разрушения и определить пределы прочности при сжатии.

Приборы и оборудование
1. Гидравлический пресс (или испытательная машина на сжатие).
2. Штангенциркуль.
3. Линейка.
4. Образец из малоуглеродистой стали (цилиндр).
5. Образец из древесины (кубик или цилиндр).

Теоретическая часть (Кратко)
При сжатии образцов важно учитывать, что пластичные и хрупкие материалы ведут себя по-разному:
- Пластичные материалы (сталь) при сжатии не разрушаются, а расплющиваются (осаживаются). Их прочность на сжатие примерно равна прочности на растяжение. Диаграмма сжатия похожа на диаграмму растяжения, но без «шейки».
- Хрупкие материалы (древесина, чугун, бетон) при сжатии разрушаются внезапно, раскалываясь на куски. Их прочность на сжатие значительно выше, чем на растяжение.

Формулы для расчетов:
Напряжение при сжатии: σ = F / A₀
где F — нагрузка (Н), A₀ — начальная площадь сечения (мм²).
Предел прочности при сжатии: σ_вс = F_max / A₀ (для хрупких материалов).
Для пластичных материалов определяется условный предел текучести (напряжение, при котором остаточная деформация достигает 0.2%).

Порядок выполнения работы

1. Подготовка образцов
Измерьте штангенциркулем размеры образцов:
- Для стального цилиндра: диаметр d₀ и высоту h₀.
- Для деревянного кубика: ширину a и высоту h₀ (или диаметр, если цилиндр).
Вычислите начальную площадь сечения A₀ для каждого образца.

2. Установка образца
Установите образец на нижнюю плиту пресса строго по центру. Опустите верхнюю плиту до соприкосновения с образцом.

3. Нагружение (Стальной образец)
Включите пресс и плавно нагружайте стальной образец. Записывайте показания силы F и осадку (изменение высоты) Δh через равные интервалы нагрузки. 
Обратите внимание: стальной образец не разрушится, он будет сплющиваться. Нагружение продолжайте до появления заметной бочкообразной формы (осадки около 30-40%).

4. Нагружение (Деревянный образец)
Установите деревянный образец. Плавно нагружайте до момента разрушения (раскалывания). Зафиксируйте максимальную силу F_max, при которой произошло разрушение. Зарисуйте характер разрушения (трещины, раскол).

5. Запись результатов
Занесите данные в таблицу. Для стали постройте график зависимости напряжения от осадки. Для дерева вычислите максимальное напряжение.

Обработка результатов

1. Для каждого замера вычислите напряжение по формуле σ = F / A₀.
2. Для стали: постройте диаграмму сжатия (σ — ε). Определите предел пропорциональности и условный предел текучести.
3. Для дерева: вычислите предел прочности при сжатии (σ_вс = F_max / A₀).
4. Сравните полученные значения с табличными данными для стали (σ_т ≈ 200-240 МПа) и древесины (σ_вс ≈ 30-50 МПа).

Контрольные вопросы
1. Почему пластичные материалы при сжатии не разрушаются, а хрупкие — раскалываются?
2. Какой материал лучше работает на сжатие: сталь или древесина? (Сравните по удельной прочности).
3. Почему для хрупких материалов при сжатии не определяют предел текучести?
4. Что такое «бочкообразование» и почему оно возникает при сжатии пластичных материалов?

Вывод (Что нужно написать в конце)
В ходе работы мы испытали на сжатие два образца: из пластичной стали и хрупкой древесины. Установлено, что сталь при сжатии пластически деформируется (сплющивается) без разрушения, в то время как древесина разрушается хрупко с образованием трещин. Полученные значения пределов прочности могут быть использованы при проектировании сжимаемых элементов конструкций (колонн, стоек, опор).
