ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 18
Тема: Расчёт мощности и выбор двигателя
========================================================================

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Изучить методы расчёта мощности двигателя для различных режимов 
   работы (продолжительный, кратковременный, повторно-кратковременный).
2. Освоить методику выбора двигателя по нагреву и перегрузочной 
   способности.
3. Научиться строить нагрузочные диаграммы.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
При выборе двигателя необходимо учитывать не только требуемую мощность, 
но и характер нагрузки (режим работы). Различают три основных режима:

1. ПРОДОЛЖИТЕЛЬНЫЙ РЕЖИМ (S1)
   Двигатель работает с постоянной нагрузкой длительное время (до 
   выхода на установившуюся температуру). Пример: привод насоса, 
   вентилятора. Мощность двигателя выбирается по статической мощности 
   на валу:
   P_дв ≥ P_нагр

2. КРАТКОВРЕМЕННЫЙ РЕЖИМ (S2)
   Двигатель работает непродолжительное время, затем отдыхает 
   (успевая остыть до температуры окружающей среды). Пример: привод 
   шлюзов, некоторых подъемников. Двигатель выбирается с учетом 
   перегрузки по мощности.

3. ПОВТОРНО-КРАТКОВРЕМЕННЫЙ РЕЖИМ (S3)
   Двигатель чередует рабочие периоды (t_раб) и паузы (t_пауза). 
   Характеризуется продолжительностью включения (ПВ):
   ПВ = (t_раб / (t_раб + t_пауза)) · 100%
   (Стандартные значения ПВ: 15%, 25%, 40%, 60%).

   Для выбора двигателя по каталогу (где указаны мощности для разных ПВ) 
   пересчет ведется по формуле:
   P_экв = P_нагр · √(ПВ_факт / ПВ_каталога)

4. НАГРЕВ И МОЩНОСТЬ
   Мощность потерь (ΔP) в двигателе идет на нагрев:
   ΔP = P_потр - P_пол
   Метод эквивалентных величин (когда нагрузка меняется по ступеням):
   - эквивалентный ток:    I_экв = √( (I1²·t1 + I2²·t2 + ...) / (t1 + t2 + ...) )
   - эквивалентная мощность: P_экв = √( (P1²·t1 + P2²·t2 + ...) / (t1 + t2 + ...) )
   - эквивалентный момент:  M_экв = √( (M1²·t1 + M2²·t2 + ...) / (t1 + t2 + ...) )

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Продолжительный режим:
  P_дв = P_нагр (с запасом 10-15%)
- Эквивалентная мощность (для ступенчатого графика):
  P_экв = √( (P1²·t1 + P2²·t2 + P3²·t3) / (t1 + t2 + t3) )
- Продолжительность включения:
  ПВ = (t_раб / (t_раб + t_пауза)) · 100%
- Пересчет мощности при изменении ПВ:
  P_дв = P_экв · √(ПВ_факт / ПВ_ст)

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта.
2. Определить режим работы двигателя.
3. Рассчитать эквивалентную мощность (если нагрузка ступенчатая) 
   или продолжительность включения (для повторно-кратковременного 
   режима).
4. Пересчитать мощность на стандартные условия (ПВ_ст).
5. Выбрать стандартную мощность двигателя из ряда (с учетом запаса).
6. Сделать вывод о влиянии режима работы на выбор мощности двигателя.
