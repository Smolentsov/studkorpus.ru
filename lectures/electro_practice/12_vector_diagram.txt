Практическое занятие N 12

Тема: Расчёт цепи переменного тока со смешанным сопротивлением R, L, C. Построение векторной диаграммы

Вариант: N ____ (по номеру в журнале)

Условия для всех вариантов: U = 100 В, f = 50 Гц, omega = 2pif = 314 рад/с.

Изобразить все схемы по описанию
Начертите в тетради принципиальные схемы соединения элементов R, L, C:

Класс А. Последовательное соединение (1 схема)
А1. R-L-C — все три элемента последовательно.
Класс Б. Параллельное соединение (1 схема)
Б1. R || L || C — все три элемента параллельно.
Класс В1. Два параллельно + третий последовательно (3 схемы)
В1.1. (L || C) - R
В1.2. (R || L) - C
В1.3. (R || C) - L
Класс В2. Два последовательно + третий параллельно (3 схемы)
В2.1. (R-L) || C
В2.2. (R-C) || L
В2.3. (L-C) || R
Итого: 8 схем. Для каждой схемы укажите: какие элементы соединены последовательно, какие — параллельно, и где включается источник U.

Порядок выполнения расчёта

Записать исходные данные своего варианта: U, f, R, X_L, X_C, схему.

Пересчитать X_L и X_C в L и C:
L = X_L / (2pif), мГн;
C = 1 / (2pif*X_C), мкФ.

Рассчитать эквивалентное сопротивление цепи методом свёртывания:
для параллельного участка — по формуле Z_пар = Z1*Z2 / sqrt(Z1^2 + Z2^2) (с учётом характера: индуктивный/ёмкостный);
для последовательного участка — Z = sqrt(R_экв^2 + (X_Lэкв - X_Cэкв)^2);
при резонансе (X_L = X_C) параллельный контур имеет бесконечное сопротивление — учесть это.

Найти общий ток: I = U / Z.

Определить токи в ветвях и напряжения на элементах (по закону Ома для участка цепи).

Построить векторную диаграмму токов и напряжений в выбранном масштабе.

Определить характер цепи (индуктивный, ёмкостный, резонансный) и сдвиг фаз phi.

Сделать вывод.

Форма отчёта
Отчёт выполняется в тетради для практических работ и содержит:
номер и тему занятия, номер варианта;
цель работы;
исходные данные варианта;
схемы всех 8 соединений (задание 1);
расчётную схему своего варианта;
формулы и пошаговые вычисления с единицами измерения;
векторную диаграмму в масштабе (на миллиметровой бумаге или в шаблоне);
вывод.

Контрольные вопросы
Чем отличается последовательное соединение R, L, C от параллельного по характеру тока и напряжения?
Как по векторной диаграмме определить, имеет цепь индуктивный или ёмкостный характер?
При каком условии в параллельном контуре L || C наступает резонанс токов и чему равно его сопротивление?
Почему в схеме (L || C) - R при X_L = X_C ток в цепи определяется только R?
Как изменится общий ток, если увеличить ёмкость C в схеме (R-L) || C?
