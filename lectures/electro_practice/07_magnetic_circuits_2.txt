========================================================================
ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 7
Тема: Расчёт разветвлённых магнитных цепей
========================================================================

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Изучить законы Кирхгофа для магнитных цепей.
2. Освоить методику расчёта разветвлённых магнитных цепей (с узлами).
3. Научиться составлять схемы замещения магнитных цепей и рассчитывать 
   их по аналогии с электрическими цепями.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
Разветвлённая магнитная цепь содержит узлы, в которых магнитный поток 
разделяется на несколько ветвей. Для расчёта таких цепей применяются 
законы, аналогичные законам Кирхгофа для электрических цепей.

1. ПЕРВЫЙ ЗАКОН КИРХГОФА ДЛЯ МАГНИТНОЙ ЦЕПИ (для узла)
   Алгебраическая сумма магнитных потоков в узле равна нулю:
   ΣΦ = 0
   *Правило знаков:* потоки, направленные к узлу, берутся с одним знаком 
   (например, «+»), от узла — с противоположным («-»).

2. ВТОРОЙ ЗАКОН КИРХГОФА ДЛЯ МАГНИТНОЙ ЦЕПИ (для контура)
   Алгебраическая сумма падений магнитного напряжения на участках 
   замкнутого контура равна алгебраической сумме МДС (F) в этом контуре:
   Σ(H_i · l_i) = Σ(I_k · w_k)
   *Правило знаков:*
   - Падение H·l берётся с «+», если направление обхода контура 
     совпадает с направлением магнитного потока.
   - МДС (I·w) берётся с «+», если при обходе контура мы идём по 
     направлению тока в обмотке (по правилу буравчика).

3. СХЕМА ЗАМЕЩЕНИЯ
   Каждый ферромагнитный участок заменяется магнитным сопротивлением 
   R_м = l / (μ0 · μ · S). Если участок нелинейный (зависит от B), 
   схема решается графоаналитическим методом или методом 
   последовательных приближений. В простейшем случае (при заданных 
   потоках) определяют H по кривым намагничивания и считают 
   напряжения по закону полного тока.

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Магнитное сопротивление участка:
  R_м = l / (μ0 · μ · S)

- Закон Ома для магнитной цепи (для участка):
  U_м = Φ · R_м = H · l

- Первый закон Кирхгофа (узел):
  Φ1 = Φ2 + Φ3

- Второй закон Кирхгофа (контур):
  H1·l1 + H2·l2 = I1·w1 - I2·w2

- Магнитная индукция:
  B = Φ / S

- Напряжённость для воздушного зазора:
  H_возд = B / μ0

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта.
2. Начертить эскиз разветвлённой магнитной цепи (указать узлы, 
   длины участков, площади сечений, обмотки).
3. Выбрать направления магнитных потоков в ветвях (в соответствии с 
   правилом буравчика).
4. Составить уравнение по первому закону Кирхгофа для магнитного узла.
5. Составить уравнения по второму закону Кирхгофа для независимых 
   контуров (с учётом заданных направлений обхода).
6. Решить полученную систему уравнений относительно магнитных потоков.
   (Для нелинейных участков предварительно найти зависимости H(Φ) по 
   кривым намагничивания).
7. Проверить правильность решения (баланс МДС или проверка по 
   контуру).
8. Сделать вывод о распределении потоков в разветвлённой цепи.
