ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Освоить методику проверки выбранного двигателя по нагреву и 
   перегрузочной способности.
2. Научиться рассчитывать пусковые токи и выбирать аппараты защиты.
3. Закрепить навыки работы с графиками нагрузки.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
Выбор двигателя по мощности не заканчивается на нахождении 
эквивалентной мощности. Выбранный двигатель обязательно проверяют 
на нагрев (в рабочем режиме) и на перегрузочную способность (на 
пиковых нагрузках).

1. ПРОВЕРКА ПО НАГРЕВУ
   Проверка заключается в сравнении эквивалентной мощности (или тока), 
   рассчитанной по графику нагрузки, с номинальной мощностью (током) 
   выбранного двигателя:
   P_ном ≥ P_экв
   Если это условие не выполняется, выбирают двигатель большей мощности.

2. ПРОВЕРКА ПО ПЕРЕГРУЗОЧНОЙ СПОСОБНОСТИ
   Двигатель не должен перегреваться и останавливаться при 
   кратковременных пиках нагрузки. Проверка ведется по максимальному 
   (пиковому) моменту:
   M_макс ≤ M_ном · K_макс
   где K_макс = M_макс / M_ном — кратность максимального момента 
   (по каталогу, для асинхронных двигателей обычно 1.8...2.5).

3. ПУСКОВЫЕ ТОКИ И ЗАЩИТА
   При пуске асинхронного двигателя ток в сети возрастает в 5...7 раз 
   по сравнению с номинальным:
   I_пуск = I_ном · K_пуск
   где K_пуск = I_пуск / I_ном — кратность пускового тока.
   
   Для защиты двигателя от коротких замыканий и перегрузок 
   используются автоматические выключатели и тепловые реле.
   Номинальный ток теплового реле выбирается исходя из номинального 
   тока двигателя:
   I_тепл = (1.0...1.2) · I_ном

4. СТУПЕНЧАТАЯ НАГРУЗКА
   Если нагрузка на валу меняется ступенями (M1, M2, M3), 
   эквивалентный момент находится по формуле:
   M_экв = √( (M1²·t1 + M2²·t2 + M3²·t3) / (t1 + t2 + t3) )

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Эквивалентный момент:       M_экв = √(Σ(Mi²·ti) / Σti)
- Эквивалентная мощность:     P_экв = M_экв · ω = M_экв · (2·π·n / 60)
- Проверка по нагреву:        P_ном ≥ P_экв
- Пусковой ток:               I_пуск = I_ном · K_пуск
- Ток теплового реле:         I_тепл = 1.1 · I_ном

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта (ступенчатый график 
   моментов).
2. Рассчитать эквивалентный момент (M_экв) по формуле.
3. Определить эквивалентную мощность (P_экв) при заданной частоте 
   вращения.
4. Выбрать номинальную мощность двигателя из стандартного ряда 
   (ближайшую большую).
5. Проверить двигатель по перегрузочной способности (сравнить 
   M_макс и M_ном · K_макс).
6. Рассчитать пусковой ток (I_пуск).
7. Выбрать ток уставки теплового реле (I_тепл).
8. Сделать вывод о правильности выбора двигателя.
