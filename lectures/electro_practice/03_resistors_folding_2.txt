ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 3
Тема: Расчёт цепей со смешанным соединением резисторов 
методом «свёртывания» (продолжение)
========================================================================

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Закрепить навыки применения метода «свёртывания» для расчёта 
   сложных смешанных цепей.
2. Научиться рассчитывать цепи с параллельными ветвями, содержащими 
   более двух резисторов.
3. Освоить методику проверки правильности выполненных расчётов 
   (баланс мощностей).

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
При расчёте сложных цепей методом «свёртывания» важно правильно 
определить последовательность шагов:
1. Начинают с самого «глубокого» участка (обычно с параллельного 
   соединения, которое находится дальше всего от источника).
2. Если на параллельном участке три и более резистора, удобно 
   использовать формулу через проводимости (G = 1/R) или считать 
   попарно.
3. После замены параллельного участка эквивалентным сопротивлением, 
   проверяют, не образовался ли новый последовательный участок, и 
   суммируют сопротивления.
4. Процесс продолжается до получения одного общего сопротивления (R_экв).

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Эквивалентное сопротивление параллельного участка (2 элемента):
  R_пар = (R1 · R2) / (R1 + R2)

- Эквивалентное сопротивление параллельного участка (n элементов):
  1/R_пар = 1/R1 + 1/R2 + ... + 1/Rn
  (Или через проводимость: G_пар = G1 + G2 + ... + Gn, где R_пар = 1/G_пар)

- Эквивалентное сопротивление последовательного участка:
  R_посл = R1 + R2 + ... + Rn

- Закон Ома для участка цепи:
  I = U / R    (или U = I · R)

- Мощность резистора:
  P = I² · R   (или P = U² / R, или P = U · I)

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта (номер в журнале).
2. Начертить принципиальную схему цепи.
3. Определить порядок «свёртывания» (показать стрелками или описать 
   словами, какие участки заменяются первыми).
4. Пошагово рассчитать эквивалентное сопротивление цепи (R_экв).
5. Рассчитать общий ток цепи (I_общ).
6. Обратным ходом (разворачивая схему) найти токи и напряжения на 
   каждом резисторе.
7. Выполнить проверку правильности расчёта, составив баланс мощностей:
   P_источника = P1 + P2 + P3 + ... + Pn
   (где P_источника = U · I_общ).
8. Сделать вывод.
