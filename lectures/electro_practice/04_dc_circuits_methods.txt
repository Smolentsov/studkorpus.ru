ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 4

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Изучить основные методы расчёта сложных электрических цепей 
   постоянного тока (законы Кирхгофа, метод контурных токов).
2. Освоить алгоритм составления уравнений для многоконтурных цепей.
3. Научиться применять правила обхода контуров и правило знаков.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
Сложная электрическая цепь содержит несколько источников ЭДС и 
несколько замкнутых контуров. Метод «свёртывания» для таких цепей 
не подходит, поэтому применяют законы Кирхгофа.

1. ПЕРВЫЙ ЗАКОН КИРХГОФА (для узлов)
   Алгебраическая сумма токов в любом узле электрической цепи равна нулю:
   ΣI = 0
   *Правило знаков:* токи, направленные к узлу, записываются с одним 
   знаком (например, «+»), а токи, направленные от узла — с 
   противоположным («-»).

2. ВТОРОЙ ЗАКОН КИРХГОФА (для контуров)
   Алгебраическая сумма падений напряжений на всех резисторах замкнутого 
   контура равна алгебраической сумме ЭДС в этом контуре:
   Σ(I · R) = ΣE
   *Правило знаков:* 
   - Произведение I·R берётся со знаком «+», если направление обхода 
     контура совпадает с направлением тока.
   - ЭДС (E) берётся со знаком «+», если при обходе контура 
     встречаем источник от «-» к «+» (т.е. ЭДС направлена по обходу).

3. МЕТОД КОНТУРНЫХ ТОКОВ
   Это метод, позволяющий сократить количество уравнений. Вместо 
   реальных токов в ветвях вводятся «контурные токи» (Ik), которые 
   замыкаются внутри каждого независимого контура.
   *Алгоритм:*
   - Выбирают независимые контуры и задают направление контурных токов 
     (обычно по часовой стрелке).
   - Для каждого контура составляют уравнение по второму закону Кирхгофа:
     Ik·(Rk + Rk1 + Rk2) - I1·R1 - I2·R2 = Ek
     (где Ik — собственный контурный ток, I1, I2 — токи смежных контуров, 
     R — сопротивления ветвей).
   - Решают систему уравнений относительно контурных токов.
   - Находят реальные токи в ветвях как алгебраическую сумму 
     контурных токов (или просто приравнивают, если ветвь принадлежит 
     только одному контуру).

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Закон Ома (для проверки):
  I = U / R

- Первый закон Кирхгофа (для узла):
  ΣI = I1 + I2 - I3 - I4 = 0

- Второй закон Кирхгофа (для контура):
  I1·R1 + I2·R2 - I3·R3 = E1 - E2

- Собственное сопротивление контура:
  R_собств = R1 + R2 + ... (сумма всех сопротивлений контура)

- Мощность источника:
  P_ист = E · I (если ток совпадает с ЭДС)

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта (номер в журнале).
2. Начертить принципиальную схему.
3. Определить количество узлов (У) и независимых контуров (К).
   (Число независимых контуров: К = В - У + 1, где В — число ветвей).
4. Выбрать и обозначить направления реальных токов в ветвях.
5. Составить уравнения по первому закону Кирхгофа для (У - 1) узлов.
6. Составить уравнения по второму закону Кирхгофа для (К) контуров, 
   задав направления обхода.
7. Решить полученную систему уравнений (относительно токов).
8. Проверить правильность решения с помощью баланса мощностей:
   ΣP_ист = Σ(I² · R)
9. Сделать вывод о методе расчёта.
