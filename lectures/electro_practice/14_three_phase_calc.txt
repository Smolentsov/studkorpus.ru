ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 14
Тема: Расчёт трёхфазной цепи переменного тока
========================================================================

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Изучить основные соотношения между линейными и фазными величинами 
   при соединении потребителей «звездой».
2. Освоить методику расчёта трёхфазной цепи при симметричной и 
   несимметричной нагрузке.
3. Научиться рассчитывать мощности в трёхфазных цепях.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
Трёхфазная цепь состоит из трёх источников ЭДС, сдвинутых по фазе 
относительно друг друга на 120°.

1. СОЕДИНЕНИЕ «ЗВЕЗДА» (Y)
   При соединении звездой концы обмоток генератора (или потребителей) 
   объединяются в общую нейтральную точку (N). 
   Начала обмоток подключаются к линейным проводам (A, B, C).
   
   Соотношения для линейных и фазных величин:
   - Линейное напряжение (U_л) — напряжение между линейными проводами 
     (U_AB, U_BC, U_CA).
   - Фазное напряжение (U_ф) — напряжение между линейным проводом и 
     нейтралью (U_A, U_B, U_C).
   
   Для симметричной системы (без нейтрального провода):
   U_л = √3 · U_ф
   I_л = I_ф
   
   (Линейный ток равен фазному току, так как фазы потребителя и 
   линия соединены последовательно).

2. СИММЕТРИЧНАЯ И НЕСИММЕТРИЧНАЯ НАГРУЗКА
   - При симметричной нагрузке (Z_A = Z_B = Z_C) токи во всех фазах 
     равны, и ток в нейтральном проводе равен нулю (I_N = 0).
   - При несимметричной нагрузке (Z_A ≠ Z_B ≠ Z_C) токи в фазах 
     разные. Если есть нейтральный провод, то напряжение на фазах 
     остается одинаковым (U_ф = U_л / √3), а ток в нейтрали 
     определяется по первому закону Кирхгофа для узла N:
     I_N = I_A + I_B + I_C (векторная сумма).
     *Важно:* при несимметричной нагрузке без нейтрального провода 
     происходит «смещение нейтрали» (фазные напряжения становятся 
     неравными).

3. МОЩНОСТИ В ТРЁХФАЗНОЙ ЦЕПИ
   - Активная мощность (P, Вт) для симметричной нагрузки:
     P = 3 · P_ф = 3 · U_ф · I_ф · cos(φ) = √3 · U_л · I_л · cos(φ)
   - Реактивная мощность (Q, вар):
     Q = √3 · U_л · I_л · sin(φ)
   - Полная мощность (S, В·А):
     S = √3 · U_л · I_л
   (Если нагрузка несимметричная, мощности каждой фазы считаются 
   отдельно и суммируются).

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Фазное напряжение при соединении звездой:
  U_ф = U_л / √3
- Полное сопротивление фазы (для последовательной R-L нагрузки):
  Z_ф = √(R_ф² + XL_ф²)
- Фазный ток (он же линейный):
  I_ф = U_ф / Z_ф
- Активная мощность фазы:
  P_ф = I_ф² · R_ф  (или P_ф = U_ф · I_ф · cos(φ))
- Реактивная мощность фазы:
  Q_ф = I_ф² · XL_ф  (или Q_ф = U_ф · I_ф · sin(φ))
- Общая активная мощность (для несимметричной нагрузки):
  P_общ = P_A + P_B + P_C
- Ток в нейтральном проводе (для несимметричной нагрузки):
  Находится векторным сложением I_A + I_B + I_C (или через проекции 
  на оси).

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта (номер в журнале).
2. Начертить принципиальную схему соединения «звезда» с нейтральным 
   проводом.
3. Определить фазные напряжения потребителей (U_ф).
4. Рассчитать полные сопротивления каждой фазы (Z_A, Z_B, Z_C), если 
   нагрузка задана через R и L.
5. Рассчитать фазные токи (I_A, I_B, I_C). При наличии нейтрального 
   провода они равны линейным токам.
6. Определить активную, реактивную и полную мощность каждой фазы и 
   общую мощность цепи.
7. Рассчитать ток в нейтральном проводе (аналитически или указать 
   метод его нахождения).
8. Сделать вывод о влиянии нейтрального провода на работу цепи при 
   несимметричной нагрузке.

   звездой?

   нейтральный провод?

   симметричной?
