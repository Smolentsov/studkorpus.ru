Тема: Расчёт трёхфазной цепи переменного тока
========================================================================

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Изучить соотношения между линейными и фазными величинами при 
   соединении «звездой».
2. Освоить методику расчёта цепи при симметричной и несимметричной 
   нагрузке.
3. Научиться рассчитывать мощности в трёхфазных цепях.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
1. СОЕДИНЕНИЕ «ЗВЕЗДА» (Y)
   Концы обмоток объединяются в нейтральную точку (N). Начала 
   подключаются к линейным проводам (A, B, C).
   - Линейное напряжение (U_л) — между линейными проводами.
   - Фазное напряжение (U_ф) — между линейным проводом и нейтралью.

   Соотношения для симметричной системы:
   U_л = √3 · U_ф
   I_л = I_ф

2. СИММЕТРИЧНАЯ И НЕСИММЕТРИЧНАЯ НАГРУЗКА
   - При симметричной нагрузке (Z_A = Z_B = Z_C) ток в нейтрали I_N = 0.
   - При несимметричной нагрузке токи разные. Если есть нейтральный 
     провод, фазные напряжения равны, ток в нейтрали определяется 
     векторной суммой: I_N = I_A + I_B + I_C.

3. МОЩНОСТИ
   Активная мощность (P): P = 3 · P_ф = √3 · U_л · I_л · cos(φ)
   Реактивная (Q): Q = √3 · U_л · I_л · sin(φ)
   Полная (S): S = √3 · U_л · I_л
   (Для несимметричной нагрузки мощности фаз суммируются).

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Фазное напряжение:     U_ф = U_л / √3
- Сопротивление фазы:    Z_ф = √(R_ф² + XL_ф²)
- Фазный ток:            I_ф = U_ф / Z_ф
- Мощность фазы:         P_ф = I_ф² · R_ф
- Ток в нейтрали:        I_N = векторная сумма (I_A + I_B + I_C)

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта.
2. Начертить схему соединения «звезда».
3. Определить фазные напряжения (U_ф).
4. Рассчитать полные сопротивления фаз (Z_A, Z_B, Z_C).
5. Рассчитать фазные токи (I_A, I_B, I_C).
6. Определить мощности каждой фазы и общую мощность.
7. Рассчитать ток в нейтральном проводе.
8. Сделать вывод.
