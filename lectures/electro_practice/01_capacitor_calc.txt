ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 1
Тема: Расчёт эквивалентной ёмкости батареи конденсаторов
========================================================================

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Изучить законы последовательного и параллельного соединения 
   конденсаторов.
2. Освоить методику расчёта эквивалентной (общей) ёмкости.
3. Научиться применять формулы для расчёта напряжений и зарядов.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
Конденсатор — устройство для накопления заряда. 
Основная характеристика — ёмкость (C), измеряется в фарадах (Ф).
   1 Ф = 10⁶ мкФ = 10⁹ нФ = 10¹² пФ.

Заряд конденсатора (Q, Кл) связан с ёмкостью и напряжением:
   Q = C · U

1. ПОСЛЕДОВАТЕЛЬНОЕ СОЕДИНЕНИЕ (C1 — C2 — C3)
   Заряд одинаков, напряжение суммируется:
   Q = Q1 = Q2 = Q3
   U = U1 + U2 + U3
   
   Эквивалентная ёмкость (для двух элементов):
   C_экв = (C1 · C2) / (C1 + C2)
   
   Для n элементов:
   1/C_экв = 1/C1 + 1/C2 + ... + 1/Cn
   
   *Общая ёмкость ВСЕГДА меньше самой маленькой.*

2. ПАРАЛЛЕЛЬНОЕ СОЕДИНЕНИЕ (C1 || C2 || C3)
   Напряжение одинаково, заряд суммируется:
   U = U1 = U2 = U3
   Q = Q1 + Q2 + Q3
   
   Эквивалентная ёмкость:
   C_экв = C1 + C2 + ... + Cn
   
   *Общая ёмкость ВСЕГДА больше самой большой.*

3. СМЕШАННОЕ СОЕДИНЕНИЕ
   Расчёт ведётся методом «свёртывания»: параллельные участки 
   считаются первыми, затем последовательные.

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Последовательный участок (2 элемента):
  C_экв = (C1 · C2) / (C1 + C2)

- Параллельный участок:
  C_экв = C1 + C2 + ... + Cn

- Общий заряд батареи:
  Q_общ = C_экв · U

- Напряжение на конденсаторе:
  U_i = Q_i / C_i

- Заряд на конденсаторе:
  Q_i = C_i · U_i

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта.
2. Начертить схему соединения конденсаторов.
3. Рассчитать эквивалентную ёмкость батареи (C_экв).
4. Рассчитать общий заряд батареи (Q_общ).
5. Найти напряжения и заряды на каждом конденсаторе.
6. Проверить баланс напряжений.
7. Сделать вывод.
