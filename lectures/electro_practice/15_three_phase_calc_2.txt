ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 15
Тема: Расчёт трёхфазной цепи переменного тока (продолжение)
========================================================================

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Изучить основные соотношения между линейными и фазными величинами 
   при соединении потребителей «треугольником».
2. Освоить методику расчёта трёхфазной цепи при симметричной и 
   несимметричной нагрузке для схемы «треугольник».
3. Научиться сравнивать схемы «звезда» и «треугольник» по 
   потребляемой мощности и токам.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
При соединении «треугольником» (Δ) начала и концы фаз потребителя 
соединяются последовательно (конец первой фазы с началом второй и т.д.), 
образуя замкнутый контур. К вершинам этого треугольника подключаются 
линейные провода (A, B, C). 

1. СООТНОШЕНИЯ ВЕЛИЧИН
   - Фазное напряжение (U_ф) равно линейному напряжению (U_л):
     U_ф = U_л
   - Линейный ток (I_л) при симметричной нагрузке больше фазного (I_ф) 
     в √3 раз:
     I_л = √3 · I_ф
   - Фазный ток (I_ф) определяется по закону Ома для каждой фазы:
     I_ф = U_ф / Z_ф

2. СИММЕТРИЧНАЯ И НЕСИММЕТРИЧНАЯ НАГРУЗКА
   - При симметричной нагрузке (Z_AB = Z_BC = Z_CA) все фазные токи 
     равны по величине и сдвинуты на 120°.
   - При несимметричной нагрузке фазные токи разные. Линейные токи в 
     этом случае определяются по первому закону Кирхгофа для узлов:
     I_A = I_AB - I_CA
     I_B = I_BC - I_AB
     I_C = I_CA - I_BC
     (Это векторные разности).
   *Особенность:* в схеме «треугольник» нет нейтрального провода, но 
   несимметрия нагрузки не приводит к смещению напряжений (каждая 
   фаза находится под фиксированным линейным напряжением).

3. МОЩНОСТИ В ТРЁХФАЗНОЙ ЦЕПИ
   - Активная мощность (P):
     P = 3 · P_ф = 3 · U_ф · I_ф · cos(φ) = √3 · U_л · I_л · cos(φ)
   - Реактивная мощность (Q):
     Q = √3 · U_л · I_л · sin(φ)
   - Полная мощность (S):
     S = √3 · U_л · I_л
   (Формулы справедливы только для симметричной нагрузки. Для 
   несимметричной — суммируют мощности каждой фазы).

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Фазное напряжение при соединении треугольником:
  U_ф = U_л
- Полное сопротивление фазы (для последовательной R-L нагрузки):
  Z_ф = √(R_ф² + XL_ф²)
- Фазный ток (закон Ома):
  I_ф = U_ф / Z_ф
- Линейный ток (для симметричной нагрузки):
  I_л = √3 · I_ф
- Линейные токи (для несимметричной нагрузки, через векторы):
  I_A = √(I_AB² + I_CA² - 2 · I_AB · I_CA · cos(60°))
  (и аналогично для других линий, если известны фазные токи)
- Активная мощность фазы:
  P_ф = I_ф² · R_ф
- Общая активная мощность (несимметричная нагрузка):
  P_общ = P_AB + P_BC + P_CA

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта.
2. Начертить принципиальную схему соединения «треугольник».
3. Определить фазные напряжения потребителей (U_ф = U_л).
4. Рассчитать полные сопротивления каждой фазы (Z_AB, Z_BC, Z_CA).
5. Рассчитать фазные токи (I_AB, I_BC, I_CA).
6. Определить линейные токи (I_A, I_B, I_C) — для симметричной 
   нагрузки через √3, для несимметричной — по первому закону Кирхгофа.
7. Рассчитать активную, реактивную и полную мощность цепи.
8. Сравнить значения линейных токов при соединении «звездой» и 
   «треугольником» для одинаковых потребителей (сделать вывод о 
   влиянии схемы на ток).

   линейному?
2. Во сколько раз линейный ток больше фазного при симметричной 
   нагрузке? Почему?
3. В какой схеме («звезда» или «треугольник») потребитель потребляет 
   большую мощность при одном и том же напряжении? Обоснуйте.

   нагрузки (обрыв)?

   сделать несимметричной?
