ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------

   тока.

   для смешанных цепей.
3. Научиться графически определять токи, напряжения и сдвиг фаз.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
Векторная диаграмма — это графическое изображение синусоидальных 
величин (токов и напряжений) вращающимися векторами. Длина вектора 
соответствует действующему значению (амплитуде), а угол наклона — 
начальной фазе.

1. ПРАВИЛА ПОСТРОЕНИЯ
   - Вектор тока в активном сопротивлении (R) совпадает по фазе с 
     вектором напряжения (U_R).
   - Вектор напряжения на индуктивности (U_L) опережает вектор тока на 
     90° (строится вверх).
   - Вектор напряжения на ёмкости (U_C) отстаёт от вектора тока на 
     90° (строится вниз).
   - При последовательном соединении за базовый вектор принимают 
     вектор тока (I).
   - При параллельном соединении за базовый вектор принимают вектор 
     напряжения (U).

2. ТОПОГРАФИЧЕСКАЯ ДИАГРАММА
   Это разновидность векторной диаграммы, где векторы напряжений 
   строятся не из одной точки, а последовательно (цепочкой). 
   Каждая точка диаграммы соответствует определенному узлу 
   электрической цепи. Построение ведется по второму закону Кирхгофа:
   U_источника = U_R + U_L + U_C (векторная сумма).

3. МЕТОД ЗАСЕЧЕК
   Если в цепи есть параллельный участок, сначала строят векторную 
   диаграмму токов для этого участка (I1 и I2), находят их сумму (I_общ). 
   Затем откладывают вектор общего тока и строят напряжения на 
   последовательных участках.

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Напряжение на участке: U = I · Z
- Падение напряжения на активном сопротивлении: U_R = I · R
- Падение напряжения на индуктивности: U_L = I · XL
- Падение напряжения на ёмкости: U_C = I · XC
- Полное напряжение цепи: U = √(U_R² + (U_L - U_C)²)
- Угол сдвига фаз: sin(φ) = (U_L - U_C) / U; cos(φ) = U_R / U; tg(φ) = (U_L - U_C) / U_R
- Масштаб по току: m_I = I_max / L_I (где L_I — длина вектора на бумаге)
- Масштаб по напряжению: m_U = U_max / L_U

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта.
2. Начертить принципиальную схему цепи.
3. Рассчитать реактивные сопротивления XL и XC.
4. Определить полное сопротивление цепи (Z_общ) и общий ток (I_общ).
5. Найти падения напряжений на всех элементах цепи.
6. Выбрать масштабы для тока (m_I) и напряжения (m_U).
7. Построить топографическую векторную диаграмму:
   - отложить базовый вектор (ток или напряжение);
   - последовательно отложить векторы напряжений на элементах;
   - проверить замыкание контура (сумма векторов должна дать вектор 
     источника).
8. Определить по диаграмме угол сдвига фаз (φ).
9. Сделать вывод.
