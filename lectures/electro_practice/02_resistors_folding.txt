========================================================================
ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 2
Тема: Расчёт цепей со смешанным соединением резисторов 
методом «свёртывания»
========================================================================

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Изучить законы последовательного и параллельного соединения 
   резисторов.
2. Освоить методику расчёта эквивалентного сопротивления цепи 
   методом «свёртывания» (упрощения схемы).
3. Научиться определять токи и напряжения на участках цепи.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
Электрическое сопротивление (R) характеризует противодействие 
проводника электрическому току и измеряется в Омах (Ом).
Закон Ома для участка цепи связывает ток (I), напряжение (U) и 
сопротивление (R):
   I = U / R

1. ПОСЛЕДОВАТЕЛЬНОЕ СОЕДИНЕНИЕ (R1 — R2 — R3)
   Ток на всех участках одинаков, напряжения складываются:
   I = I1 = I2 = I3
   U = U1 + U2 + U3
   
   Эквивалентное сопротивление (просто сумма):
   R_экв = R1 + R2 + ... + Rn
   
   *Общее сопротивление ВСЕГДА больше самого большого.*

2. ПАРАЛЛЕЛЬНОЕ СОЕДИНЕНИЕ (R1 || R2 || R3)
   Напряжение на всех ветвях одинаково, токи складываются:
   U = U1 = U2 = U3
   I = I1 + I2 + I3
   
   Эквивалентное сопротивление (для двух элементов):
   R_экв = (R1 · R2) / (R1 + R2)
   
   Для n элементов:
   1/R_экв = 1/R1 + 1/R2 + ... + 1/Rn
   
   *Общее сопротивление ВСЕГДА меньше самого маленького.*

3. СМЕШАННОЕ СОЕДИНЕНИЕ И МЕТОД «СВЁРТЫВАНИЯ»
   Если в цепи есть и последовательные, и параллельные участки, 
   расчёт ведётся пошагово:
   Шаг 1. Находят участки с явным параллельным соединением и заменяют 
           их эквивалентным сопротивлением.
   Шаг 2. Полученную упрощённую схему проверяют на наличие 
           последовательных участков и суммируют их.
   Шаг 3. Процесс повторяют до тех пор, пока не останется одно 
           общее сопротивление R_экв.

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Последовательный участок:
  R_экв = R1 + R2 + ... + Rn
  I_общ = I1 = I2
  U_общ = U1 + U2

- Параллельный участок (2 резистора):
  R_экв = (R1 · R2) / (R1 + R2)
  U_общ = U1 = U2
  I_общ = I1 + I2

- Закон Ома для всей цепи:
  I_общ = U / R_экв

- Закон Ома для участка:
  U_участка = I_участка · R_участка

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта (согласно номеру в журнале).
2. Начертить принципиальную схему цепи.
3. Определить порядок «свёртывания» (какие резисторы соединены 
   параллельно, а какие — последовательно).
4. Пошагово вычислить эквивалентное сопротивление цепи (R_экв), 
   записывая промежуточные формулы.
5. Найти общий ток в цепи по закону Ома для полной цепи.
6. Обратным ходом (разворачивая схему) найти токи и напряжения на 
   каждом резисторе.
7. Проверить баланс мощностей (или баланс токов/напряжений).
8. Сделать вывод о влиянии смешанного соединения на общее сопротивление.

   известен ток через него?
