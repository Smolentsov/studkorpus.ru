ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 5
Тема: Расчёт цепи постоянного тока разными методами (продолжение)
========================================================================

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Закрепить навыки составления уравнений по законам Кирхгофа.
2. Освоить метод узловых потенциалов (МУП) для расчёта сложных цепей.
3. Научиться выбирать наиболее рациональный метод расчёта в 
   зависимости от структуры цепи.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
Метод узловых потенциалов (МУП) основан на применении первого закона 
Кирхгофа. В этом методе неизвестными величинами являются потенциалы 
узлов цепи (φ). Потенциал одного из узлов (обычно самого «загруженного») 
принимают равным нулю (заземляют).

*Алгоритм МУП:*
1. Определяют число узлов (У) в цепи. Один узел заземляют (φ = 0).
2. Для оставшихся (У - 1) узлов составляют систему уравнений.
3. Собственная проводимость узла (G_ii) равна сумме проводимостей 
   всех ветвей, сходящихся в i-м узле.
4. Межузловая проводимость (G_ij) равна сумме проводимостей ветвей, 
   соединяющих i-й и j-й узлы (берётся со знаком «-» в уравнении).
5. Узловой ток (I_ii) равен алгебраической сумме токов короткого 
   замыкания ветвей, сходящихся в узле. Токи, направленные к узлу, 
   берут со знаком «+», от узла — «-».
6. Решают систему уравнений относительно потенциалов узлов (φ).
7. Находят реальные токи в ветвях по закону Ома, используя найденные 
   потенциалы.

*Формула для тока ветви между узлами «a» и «b»:*
I_ab = (φ_a - φ_b + E_ab) / R_ab
(где E_ab — ЭДС в ветви, направленная от a к b).

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Проводимость ветви:
  G = 1 / R

- Система уравнений для двух узлов (a и b):
  G_aa · φ_a - G_ab · φ_b = I_aa
  -G_ba · φ_a + G_bb · φ_b = I_bb

- Собственная проводимость узла (для узла «a»):
  G_aa = G1 + G2 + G3 + ...

- Межузловая проводимость (между узлами «a» и «b»):
  G_ab = G_ba = G1 + G2 + ... (проводимости ветвей между этими узлами)

- Ток в ветви (по закону Ома):
  I = (φ_нач - φ_кон + E) / R

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта.
2. Начертить схему и определить количество узлов.
3. Принять потенциал одного узла равным нулю.
4. Составить систему уравнений по методу узловых потенциалов 
   (используя формулы собственных и межузловых проводимостей).
5. Решить систему уравнений, найдя потенциалы узлов.
6. Рассчитать токи в ветвях, используя найденные потенциалы.
7. Проверить решение с помощью баланса мощностей.
8. Сравнить трудоемкость МУП с методом контурных токов для данной цепи 
   (сделать вывод).
