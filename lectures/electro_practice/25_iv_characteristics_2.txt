ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Изучить входные и выходные вольтамперные характеристики 
   биполярного транзистора.
2. Освоить методику построения семейства выходных характеристик.
3. Научиться определять коэффициент усиления по току (h21э или β) 
   по характеристикам.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
Биполярный транзистор — это трёхэлектродный полупроводниковый прибор 
(База, Коллектор, Эмиттер), который используется для усиления и 
переключения сигналов. В зависимости от схемы включения (с общей базой, 
общим эмиттером, общим коллектором) его характеристики различаются. 
Наибольшее распространение получила схема с **общим эмиттером (ОЭ)**.

1. ВХОДНАЯ ХАРАКТЕРИСТИКА (для схемы с ОЭ)
   Это зависимость тока базы (I_б) от напряжения база-эмиттер (U_бэ) 
   при постоянном напряжении коллектор-эмиттер (U_кэ = const).
   - По форме напоминает ВАХ диода (переход Б-Э открывается при 
     U_бэ ≈ 0.6...0.7 В для кремния).
   - При увеличении U_бэ ток базы резко возрастает.

2. ВЫХОДНАЯ ХАРАКТЕРИСТИКА (для схемы с ОЭ)
   Это зависимость тока коллектора (I_к) от напряжения 
   коллектор-эмиттер (U_кэ) при фиксированном токе базы (I_б = const).
   - Семейство кривых для разных значений I_б.
   - В начальной области (U_кэ < 1 В) ток коллектора резко растет 
     (режим насыщения).
   - Затем наступает пологая часть (активный режим), где I_к почти 
     не зависит от U_кэ и определяется током базы.

3. КОЭФФИЦИЕНТ УСИЛЕНИЯ ПО ТОКУ (h21э)
   Показывает, во сколько раз ток коллектора больше тока базы в 
   активном режиме:
   h21э = ΔI_к / ΔI_б
   (При постоянном U_кэ).

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Коэффициент усиления по току:
  h21э = (I_к2 - I_к1) / (I_б2 - I_б1)
- Ток коллектора (общий):
  I_к = h21э · I_б + I_к0 (где I_к0 — обратный ток коллектора, мал)
- Мощность, рассеиваемая на коллекторе:
  P_к = U_кэ · I_к

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта (значения токов и 
   напряжений).
2. Построить график входной характеристики: по оси X — U_бэ (В), 
   по оси Y — I_б (мА).
3. Построить график выходных характеристик: по оси X — U_кэ (В), 
   по оси Y — I_к (мА). Нанести несколько кривых для разных значений 
   тока базы (I_б1, I_б2, I_б3).
4. По выходным характеристикам выбрать рабочую точку (например, при 
   U_кэ = 5 В) и определить ток коллектора для двух значений тока базы.
5. Рассчитать коэффициент усиления по току (h21э).
6. Сделать вывод о работе транзистора в активном режиме.
