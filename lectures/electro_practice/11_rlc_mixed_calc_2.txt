ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 11
Тема: Расчёт цепи переменного тока со смешанным сопротивлением R, L, C
(продолжение)
========================================================================

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Закрепить навыки расчёта сложных цепей переменного тока методом 
   проводимостей.
2. Освоить расчёт цепей, в которых параллельные ветви сами содержат 
   последовательные соединения элементов.
3. Научиться определять распределение токов и напряжений в 
   разветвлённых цепях.

КРАТКИЕ ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
В данной работе рассматривается цепь, состоящая из двух параллельных 
ветвей:
- Ветвь 1: катушка индуктивности (последовательно R1 и L).
- Ветвь 2: конденсатор (последовательно R2 и C).

Общее напряжение U приложено к обеим ветвям.
Для расчёта такой цепи удобно использовать метод проводимостей. 
Сначала находят полные сопротивления каждой ветви, затем их активные 
и реактивные проводимости.

1. РАСЧЁТ ПРОВОДИМОСТЕЙ
   Для ветви 1 (R1, L):
   Z1 = √(R1² + XL²)
   Активная проводимость: g1 = R1 / Z1²
   Реактивная индуктивная проводимость: b_L = XL / Z1²

   Для ветви 2 (R2, C):
   Z2 = √(R2² + XC²)
   Активная проводимость: g2 = R2 / Z2²
   Реактивная ёмкостная проводимость: b_C = XC / Z2²

2. ОБЩИЕ ПАРАМЕТРЫ ЦЕПИ
   Общая активная проводимость: G = g1 + g2
   Общая реактивная проводимость: B = b_L - b_C
   (так как индуктивный и ёмкостный токи направлены противоположно).
   Полная проводимость цепи: Y = √(G² + B²)
   Общий ток цепи: I = U · Y

3. ТОКИ В ВЕТВЯХ
   Токи в ветвях определяются по закону Ома:
   I1 = U / Z1
   I2 = U / Z2
   (Векторная сумма этих токов дает общий ток I).

4. МОЩНОСТИ
   Активная мощность: P = U² · G
   Реактивная мощность: Q = U² · B
   Полная мощность: S = U · I

ФОРМУЛЫ ДЛЯ РАСЧЁТА
------------------------------------------------------------------------
- Угловая частота: ω = 2 · π · f
- Сопротивления: XL = ω · L; XC = 1 / (ω · C)
- Полные сопротивления ветвей:
  Z1 = √(R1² + XL²)
  Z2 = √(R2² + XC²)
- Проводимости ветвей:
  g1 = R1 / Z1²;  b_L = XL / Z1²
  g2 = R2 / Z2²;  b_C = XC / Z2²
- Общая проводимость: Y = √( (g1 + g2)² + (b_L - b_C)² )
- Общий ток: I = U · Y
- Токи в ветвях: I1 = U / Z1;  I2 = U / Z2
- Сдвиг фаз: tg(φ) = (b_L - b_C) / (g1 + g2)

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
1. Записать исходные данные своего варианта.
2. Начертить принципиальную схему (две параллельные ветви: R1-L и R2-C).
3. Рассчитать угловую частоту (ω), сопротивления XL и XC.
4. Найти полные сопротивления каждой ветви (Z1 и Z2).
5. Рассчитать активные и реактивные проводимости ветвей (g1, b_L, 
   g2, b_C).
6. Определить общую проводимость цепи (Y) и общий ток (I).
7. Найти токи в ветвях (I1 и I2).
8. Рассчитать мощности (P, Q, S) и сдвиг фаз (tg(φ)).
9. Сделать вывод о характере цепи.
