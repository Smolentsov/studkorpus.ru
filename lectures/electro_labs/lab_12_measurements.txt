ЭЛЕКТРОИЗМЕРИТЕЛЬНЫЕ ПРИБОРЫ И ИЗМЕРЕНИЯ ЭЛЕКТРИЧЕСКИХ ВЕЛИЧИН

ЦЕЛЬ РАБОТЫ
------------------------------------------------------------------------
1. Изучить устройство и принцип действия аналоговых электроизмерительных
   приборов (амперметра и вольтметра).
2. Научиться определять цену деления и пределы измерения прибора.
3. Освоить методику снятия показаний и оценки абсолютной и относительной
   погрешности измерений.

ОБОРУДОВАНИЕ
------------------------------------------------------------------------
- Амперметр аналоговый лабораторный
- Вольтметр аналоговый лабораторный
- Источник питания
- Набор резисторов
- Соединительные провода
- Ключ

ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ
------------------------------------------------------------------------
1. Цена деления (ЦД) — разность значений между двумя соседними
   оцифрованными штрихами, делённая на число промежутков между ними:

       ЦД = (X_max - X_min) / N

   где X_max, X_min — значения ближайших оцифрованных штрихов,
   N — число промежутков между ними.

2. Инструментальная погрешность аналогового прибора принимается равной
   половине цены деления:

       Δ = ЦД / 2

3. Правила включения:
   - амперметр включается в цепь ПОСЛЕДОВАТЕЛЬНО с нагрузкой;
   - вольтметр включается ПАРАЛЛЕЛЬНО нагрузке.

4. Относительная погрешность:

       ε = (Δ / X_изм) * 100 %

5. Закон Ома для участка цепи:

       I = U / R    =>    R = U / I

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ
------------------------------------------------------------------------
Задание 1. Определение характеристик приборов и цены деления
  1.1. Рассмотрите шкалы амперметра и вольтметра.
  1.2. Определите предел измерения (максимальное значение шкалы).
  1.3. Вычислите цену деления по формуле.
  1.4. Запишите инструментальную погрешность (половина цены деления).

Задание 2. Снятие показаний
  2.1. Соберите цепь: источник питания — ключ — резистор — амперметр
       (последовательно); вольтметр подключите параллельно резистору.
  2.2. Замкните ключ и снимите показание амперметра (с учётом цены
       деления).
  2.3. Снимите показание вольтметра.
  2.4. Разомкните ключ.

Задание 3. Проверка закона Ома
  3.1. Рассчитайте сопротивление по показаниям приборов: R = U / I.
  3.2. Сравните полученное значение с номиналом резистора.

Задание 4. Оценка погрешностей
  4.1. Рассчитайте абсолютную погрешность измерения тока и напряжения:
       ΔI = ЦД(I) / 2;   ΔU = ЦД(U) / 2.
  4.2. Вычислите относительную погрешность:
       ε(I) = (ΔI / I_изм) * 100 %;
       ε(U) = (ΔU / U_изм) * 100 %.

КОНТРОЛЬНЫЕ ВОПРОСЫ
------------------------------------------------------------------------
1. Почему амперметр нельзя включать параллельно источнику питания?
2. Как изменится показание вольтметра, если его сопротивление будет
   недостаточно большим по сравнению с сопротивлением нагрузки?
3. Определите цену деления вольтметра, если его шкала имеет 30 делений,
   а предел измерения равен 6 В.
4. Чему равна инструментальная погрешность прибора, если цена деления
   равна 0,2 В?

- расчёт абсолютных и относительных погрешностей;
- ответы на контрольные вопросы;
