========================================================================

ЦЕЛЬ ВТОРОЙ ЧАСТИ
------------------------------------------------------------------------
1. Показать умение оформлять результаты измерений в тетради.
2. Продемонстрировать правильность подключения приборов на стенде.
3. Показать знание устройства подключённого прибора.
4. Показать знание шкалы, цены деления, точности и других характеристик
   прибора.

ОБОРУДОВАНИЕ
------------------------------------------------------------------------
- Стенд с собранной электрической цепью (источник, резистор, ключ,
  амперметр, вольтметр)
- Тетрадь с отчётом по первой части работы
- Методичка по лабораторной работе № 12

ПОРЯДОК ВЫПОЛНЕНИЯ
------------------------------------------------------------------------
Работа выполняется по этапам. Каждый этап студент проходит
самостоятельно и предъявляет преподавателю. Преподаватель ставит
отметку о прохождении этапа.

ЭТАП 2. ПРАВИЛЬНОСТЬ ПОДКЛЮЧЕНИЯ НА СТЕНДЕ
========================================================================

преподавателю, что приборы подключены правильно.

========================================================================
ЭТАП 4. ЗНАНИЕ ШКАЛЫ, ЦЕНЫ ДЕЛЕНИЯ, ТОЧНОСТИ И ДАННЫХ ПРИБОРА
========================================================================

Заполните таблицу по прибору, установленному на вашем стенде.
Все данные берите с корпуса прибора и со шкалы.

+-----------------------------------------------------------------------+
| ХАРАКТЕРИСТИКА ПРИБОРА                    | ЗНАЧЕНИЕ                  |
+-------------------------------------------+---------------------------+
| Название прибора                          |                           |
| Назначение прибора                        |                           |
| Тип прибора (система)                     |                           |
| Род измеряемого тока                      |                           |
| Предел измерения (X_max)                  |                           |
| Начало шкалы (X_min)                      |                           |
| Число делений шкалы (N)                   |                           |
| Цена деления (ЦД)                         |                           |
| Класс точности                            |                           |
| Инструментальная погрешность (Δ)          |                           |
| Положение стрелки (число делений)         |                           |
| Показание прибора                         |                           |
| Относительная погрешность измерения       |                           |
+-------------------------------------------+---------------------------+

Формулы для расчёта:
    ЦД = (X_max - X_min) / N
    Δ = ЦД / 2   (или Δ = (класс точности / 100) * X_max)
    ε = (Δ / X_изм) * 100 %

Ответьте преподавателю:
[ ] Как определить цену деления шкалы?
[ ] Чем отличается класс точности от цены деления?
[ ] При каком положении стрелки относительная погрешность минимальна
    и почему?
[ ] Как выбрать предел измерения, чтобы погрешность была минимальной?
