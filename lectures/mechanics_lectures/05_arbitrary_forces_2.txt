Лекция 5. Плоская система произвольно расположенных сил: равновесие

Вступление
В прошлой лекции мы научились приводить любую систему сил к главному вектору и главному моменту. Но инженеру чаще всего нужно не просто узнать, куда двинется тело, а сделать так, чтобы оно никуда не двигалось. То есть обеспечить равновесие.

Сегодня мы сформулируем главные уравнения статики, с помощью которых рассчитывают мосты, краны, строительные фермы и любые неподвижные конструкции.

Часть 1. Условия равновесия произвольной плоской системы сил

Тело находится в равновесии, если равнодействующая всех сил равна нулю и суммарный момент тоже равен нулю. 

Геометрическое условие равновесия: 
Силовой многоугольник замкнут, а многоугольник моментов равен нулю.

Аналитическое условие равновесия (используется при решении задач):
Для равновесия произвольной плоской системы сил необходимо и достаточно, чтобы сумма проекций всех сил на две взаимно перпендикулярные оси (X и Y) и сумма моментов всех сил относительно любой точки (О) были равны нулю.

ΣF_x = 0
ΣF_y = 0
ΣM_O = 0

Эта система из трех уравнений называется основной формой уравнений равновесия.

Часть 2. Другие формы уравнений равновесия

Иногда удобнее составлять уравнения по-другому. Для плоской системы сил существуют еще две формы уравнений равновесия:

Вторая форма (форма моментов):
Сумма моментов всех сил относительно двух любых точек (А и В) и сумма проекций на ось (не перпендикулярную линии, соединяющей эти точки).
ΣM_A = 0
ΣM_B = 0
ΣF_x = 0
(Точки А и В не должны лежать на одной прямой с осью X).

Третья форма (форма трех моментов):
Сумма моментов всех сил относительно трех любых точек (А, В, С), не лежащих на одной прямой.
ΣM_A = 0
ΣM_B = 0
ΣM_C = 0

На практике чаще всего используют первую (основную) форму: две оси (X, Y) и одна точка для моментов. В качестве точки для моментов обычно выбирают ту, где сходятся неизвестные реакции опор, чтобы они "обнулились" в уравнении.

Часть 3. Как решать задачи на равновесие (Алгоритм)

Решение задач на равновесие всегда выполняется по одному и тому же плану:
1. Выбрать тело (или узел), равновесие которого мы рассматриваем.
2. Освободить его от связей и заменить их действие реакциями (нарисовать силы).
3. Выбрать оси координат (обычно одну ось направляют вдоль неизвестной силы или вдоль балки).
4. Выбрать точку для составления уравнения моментов (обычно это точка, где приложены две неизвестные реакции, чтобы они не вошли в уравнение).
5. Составить уравнения равновесия (ΣF_x = 0, ΣF_y = 0, ΣM = 0).
6. Решить систему уравнений и найти неизвестные реакции.
7. Сделать проверку (составить уравнение моментов относительно другой точки и убедиться, что сумма равна нулю).

Часть 4. Пример (мысленный эксперимент)

Представьте балку, лежащую на двух опорах. На нее действует сила тяжести.
1. Мы освобождаем балку от опор и заменяем их реакциями (в опорах возникают вертикальные силы).
2. Проводим ось Y вверх, ось X вдоль балки.
3. Уравнение ΣF_x = 0 покажет, что горизонтальных сил нет, значит, горизонтальные реакции равны нулю.
4. Уравнение ΣM относительно левой опоры покажет, как правая опора держит балку (там будет только одна неизвестная сила).
5. Уравнение ΣF_y = 0 покажет, как левая опора держит балку (сумма реакций равна весу).

Проверьте себя
1. Сколько уравнений нужно составить для равновесия плоской системы сил?
2. Почему для составления уравнения моментов выбирают точку, где сходятся неизвестные силы?
3. В чем отличие первой формы уравнений от третьей?
4. Что мы делаем на шаге «освобождение от связей»?

Заключение
Уравнения равновесия — это главный рабочий инструмент инженера. С их помощью можно рассчитать любую неподвижную конструкцию. В следующей лекции мы применим эти знания к конкретным типам конструкций — балочным системам и их опорам.
