ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 5 (часть 2)
Тема: Определение центра тяжести стандартных прокатных профилей: закрепление и защита

Цель работы: Закрепление умений определять координаты центра тяжести сложного сечения, составленного из стандартных прокатных профилей, а также защита выполненной работы (части 1 и 2).

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Выполненная работа ПЗ №5 (часть 1), конспект лекций, справочные таблицы (сортамент прокатных профилей), калькулятор.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. На защите студент должен показать выполненную часть 1 (схему и расчет координат) и ответить на вопросы преподавателя.
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. ПРОВЕРКА ВЫПОЛНЕННОЙ РАБОТЫ (ЧАСТЬ 1)
--------------------------------------------------
Перед защитой убедитесь, что в вашей работе (часть 1) присутствуют следующие элементы:
1. Схема сложного сечения (три профиля: двутавр, швеллер, уголок) с указанием осей X и Y и координат центров тяжести каждого профиля (x1, y1), (x2, y2), (x3, y3).
2. Выписка из сортамента для каждого профиля: площадь поперечного сечения (A1, A2, A3) и координаты центров тяжести (x_i, y_i).
3. Расчет координат центра тяжести всего сечения (X_C, Y_C).
4. Нанесение найденного центра тяжести (точки C) на схему с подписью координат.
5. Проверка правильности расчета (сумма моментов площадей относительно центра тяжести близка к нулю).

Если какой-либо элемент отсутствует, дополните работу до начала защиты.

--------------------------------------------------
ЗАДАНИЕ 2. ДОПОЛНИТЕЛЬНЫЙ РАСЧЕТ (ДЛЯ ЗАКРЕПЛЕНИЯ)
--------------------------------------------------
Для закрепления материала выполните дополнительный расчет: определите координаты центра тяжести для другого сочетания профилей (по варианту).

Исходные данные для дополнительного расчета:
- Двутавр № (15 + N) (где N — ваш номер по журналу).
- Швеллер № (10 + N).
- Уголок равнополочный № (8 + N).

Взаимное расположение (начертите схему):
- Двутавр расположен горизонтально, его центр тяжести в точке (x1; y1) = (0; 0).
- Швеллер расположен вертикально, его центр тяжести в точке (x2; y2) = (12 + N; 0).
- Уголок расположен над швеллером, его центр тяжести в точке (x3; y3) = (12 + N; 12 + N).

Требуется:
1. Начертите схему сечения с указанием профилей и координат их центров тяжести.
2. Выпишите из сортамента площади и координаты для новых профилей.
3. Рассчитайте координаты центра тяжести (X_C2, Y_C2) по формулам:
   X_C2 = (A1*x1 + A2*x2 + A3*x3) / (A1 + A2 + A3)
   Y_C2 = (A1*y1 + A2*y2 + A3*y3) / (A1 + A2 + A3)
   Округлите до двух знаков после запятой.
4. Нанесите точку C2 на схему и подпишите координаты.
5. Выполните проверку: сумма моментов площадей относительно найденного центра тяжести должна быть равна нулю (с учетом знаков).
6. Сделайте вывод (1–2 предложения): как изменилось положение центра тяжести по сравнению с частью 1 (если профили стали больше по номеру, центр тяжести сместился в сторону более тяжелого профиля; если координаты изменились, центр тяжести сместился вправо и вверх).

--------------------------------------------------
ЗАДАНИЕ 3. ЗАЩИТА РАБОТЫ (УСТНО ИЛИ ПИСЬМЕННО)
--------------------------------------------------
Ответьте на следующие вопросы (развернуто, 2–3 предложения на каждый):

1. Что такое центр тяжести тела и для чего его определяют в инженерных расчетах? (Ответ: центр тяжести — это точка, через которую проходит равнодействующая сил тяжести всех частиц тела. Его определяют для расчета устойчивости конструкций, при проектировании опор и подвесов, а также для определения рационального расположения элементов.)
2. Как определяются координаты центра тяжести сложного сечения, составленного из стандартных профилей? (Ответ: сложное сечение разбивают на простые части (профили), для каждой находят площадь и координаты центра тяжести по сортаменту, затем используют формулы: X_C = Σ(A_i * x_i) / ΣA_i; Y_C = Σ(A_i * y_i) / ΣA_i.)
3. Почему при расчете центра тяжести сложного сечения важно учитывать знаки координат? (Ответ: если профили расположены в разных квадрантах, их координаты могут быть отрицательными. Неучет знаков приведет к неверному положению центра тяжести.)
4. Как проверить правильность найденного центра тяжести? (Ответ: нужно составить сумму моментов площадей относительно найденного центра тяжести. Если центр тяжести найден верно, эта сумма должна быть равна нулю (с учетом погрешности округления).)
5. Как влияет номер профиля (его площадь) на положение центра тяжести всего сечения? (Ответ: чем больше площадь профиля, тем ближе к нему смещается центр тяжести всего сечения. Если профиль тяжелее, его «вес» в формуле больше, поэтому координата центра тяжести смещается в его сторону.)

--------------------------------------------------
ЗАДАНИЕ 4. ИТОГОВЫЙ ВЫВОД
--------------------------------------------------
Напишите итоговый вывод по всей работе (3–5 предложений), в котором отразите:
1. Какие профили входили в состав сечения (часть 1 и часть 2).
2. Какие координаты центра тяжести были получены для каждого варианта.
3. Как изменилось положение центра тяжести при изменении состава профилей (сравните часть 1 и часть 2).
4. Для чего в инженерной практике необходимо определять центр тяжести сложных сечений.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- Двутавр № 20: A1 = 26,8 см²; x1 = 0; y1 = 0.
- Швеллер № 15: A2 = 18,1 см²; x2 = 12 + 5 = 17 см; y2 = 0.
- Уголок № 13: A3 = 20,4 см²; x3 = 17 см; y3 = 17 см.
X_C2 = (26,8*0 + 18,1*17 + 20,4*17) / (26,8 + 18,1 + 20,4) = (0 + 307,7 + 346,8) / 65,3 = 654,5 / 65,3 ≈ 10,02 см.
Y_C2 = (26,8*0 + 18,1*0 + 20,4*17) / 65,3 = 346,8 / 65,3 ≈ 5,31 см.
Проверка: Σ(A_i*(x_i - X_C2)) = 26,8*(0 - 10,02) + 18,1*(17 - 10,02) + 20,4*(17 - 10,02) = 26,8*(-10,02) + 18,1*6,98 + 20,4*6,98 = -268,54 + 126,34 + 142,39 = 0,19 ≈ 0 (сходится).
Σ(A_i*(y_i - Y_C2)) = 26,8*(0 - 5,31) + 18,1*(0 - 5,31) + 20,4*(17 - 5,31) = 26,8*(-5,31) + 18,1*(-5,31) + 20,4*11,69 = -142,31 - 96,11 + 238,48 = 0,06 ≈ 0 (сходится).
