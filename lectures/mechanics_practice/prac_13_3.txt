ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 13 (часть 3)
Тема: Расчет основных геометрических характеристик зубчатых передач: проверочный расчет

Цель работы: Формирование умений выполнять проверочный расчет зубчатой передачи на контактную выносливость и выносливость при изгибе, а также делать вывод о работоспособности передачи.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите эскиз зуба (от руки, с соблюдением пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. ПРОВЕРОЧНЫЙ РАСЧЕТ НА КОНТАКТНУЮ ВЫНОСЛИВОСТЬ
--------------------------------------------------
Прямозубая цилиндрическая передача (из предыдущих занятий) должна работать длительное время без разрушения контактных поверхностей зубьев.
Исходные данные для расчета (используйте результаты ПЗ №13, часть 1 и 2):
- Вращающий момент на валу шестерни: T1 = (N + 10) Н·м (где N — ваш номер по журналу).
- Делительный диаметр шестерни: d1 (из ПЗ №13, часть 1).
- Передаточное число: u (из ПЗ №13, часть 1).
- Ширина венца колеса: b2 (из ПЗ №13, часть 1).
- Коэффициент, учитывающий неравномерность распределения нагрузки по ширине венца: K_Hβ = 1,1 (принято для учебного расчета).
- Материал зубчатых колес: Сталь 40Х, допускаемое контактное напряжение [σ_H] = 500 МПа.

Что необходимо сделать:
1. Рассчитайте контактное напряжение в зацеплении (σ_H) по упрощенной формуле:
   σ_H = Z_H * Z_M * sqrt( (2 * T1 * K_Hβ * (u + 1)) / (b2 * d1^2 * u) )
   где:
   - Z_H = 1,77 (коэффициент, учитывающий форму сопряженных поверхностей зубьев);
   - Z_M = 275 (коэффициент, учитывающий механические свойства материалов, МПа^(1/2));
   - T1 — в Н·м;
   - d1 — в м (переведите мм в м, разделив на 1000);
   - b2 — в м (переведите мм в м).
2. Сравните полученное контактное напряжение с допускаемым: σ_H ≤ [σ_H]. Запишите условие прочности.
3. Сделайте вывод (1–2 предложения): выполняется ли условие контактной выносливости. Если σ_H > [σ_H], укажите, какие параметры передачи (например, ширину венца или модуль) нужно увеличить, чтобы обеспечить прочность.

--------------------------------------------------
ЗАДАНИЕ 2. ПРОВЕРОЧНЫЙ РАСЧЕТ НА ВЫНОСЛИВОСТЬ ПРИ ИЗГИБЕ
--------------------------------------------------
Требуется:
1. Рассчитайте напряжение изгиба в основании зуба шестерни (σ_F1) по упрощенной формуле:
   σ_F1 = (F_t * K_Fβ * Y_FS1) / (b1 * m)
   где:
   - F_t — окружная сила (из ПЗ №13, часть 2), Н;
   - K_Fβ = 1,2 (коэффициент, учитывающий неравномерность распределения нагрузки по ширине венца);
   - Y_FS1 = 3,8 (коэффициент, учитывающий форму зуба шестерни при z1, взятый из таблицы, для учебного расчета примем среднее значение);
   - b1 — ширина венца шестерни (из ПЗ №13, часть 1), мм;
   - m — модуль зацепления (из ПЗ №13, часть 1), мм.
2. Рассчитайте напряжение изгиба в основании зуба колеса (σ_F2) по формуле:
   σ_F2 = (F_t * K_Fβ * Y_FS2) / (b2 * m)
   где:
   - Y_FS2 = 3,6 (коэффициент формы зуба колеса, примем среднее значение);
   - b2 — ширина венца колеса, мм.
3. Сравните полученные напряжения с допускаемыми:
   - для шестерни: [σ_F1] = 300 МПа;
   - для колеса: [σ_F2] = 250 МПа.
4. Сделайте вывод (1–2 предложения): выполняется ли условие изгибной выносливости для шестерни и колеса. Если нет, укажите, какой параметр нужно изменить (например, увеличить модуль).

--------------------------------------------------
ЗАДАНИЕ 3. ПОСТРОЕНИЕ ЭСКИЗА ЗУБА
--------------------------------------------------
Требуется:
1. Начертите эскиз зуба шестерни (вид сбоку) с указанием основных геометрических параметров:
   - Делительная окружность (штрихпунктирная линия);
   - Окружность вершин (сплошная линия);
   - Окружность впадин (сплошная линия);
   - Модуль m (покажите как расстояние между одноименными точками соседних зубьев);
   - Высота зуба h (покажите как расстояние от окружности вершин до окружности впадин).
2. Подпишите все элементы на эскизе.
3. Напишите вывод (1–2 предложения): как модуль зацепления влияет на прочность зуба на изгиб (при увеличении модуля прочность растет, так как увеличивается толщина зуба в основании).
