ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 3
Тема: Определение реакций опор в 2х опорной балке

Цель работы: Формирование умений определять опорные реакции двухопорной балки (шарнирно-подвижная и шарнирно-неподвижная опоры), составлять уравнения равновесия и выполнять проверку правильности решения.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите расчетную схему балки (от руки, с соблюдением масштаба и пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. ОПРЕДЕЛЕНИЕ ОПОРНЫХ РЕАКЦИЙ
--------------------------------------------------
Двухопорная балка АВ нагружена системой внешних сил.
На балку действуют:
- Сосредоточенная сила P = 10 + 2*N кН (где N — ваш номер по журналу), приложенная в точке С (на расстоянии l1 от левой опоры А).
- Распределенная нагрузка q = 2 + 0,5*N кН/м, приложенная на участке от точки С до правой опоры В.
- Сосредоточенный момент M = 5 + N кН·м, приложенный в точке В (направлен по часовой стрелке).

Геометрия балки:
- Длина участка АС: l1 = 2 + 0,1*N м (округлите до десятых).
- Длина участка СВ: l2 = 3 + 0,2*N м (округлите до десятых).
- Общая длина балки: L = l1 + l2 (в метрах).

Типы опор:
- Левая опора А — шарнирно-неподвижная (реакция имеет две составляющие: R_Ax и R_Ay).
- Правая опора В — шарнирно-подвижная (реакция направлена вертикально: R_B).

Что необходимо сделать:
1. Начертите расчетную схему балки. Нанесите все действующие нагрузки (P, q, M) и укажите длины участков (l1, l2). Обозначьте опоры А и В, покажите предполагаемые направления реакций (R_Ax, R_Ay, R_B).
2. Замените распределенную нагрузку q на сосредоточенную силу Q = q * l2 (в кН), приложенную посередине участка СВ (на расстоянии l2/2 от точки С и на расстоянии l1 + l2/2 от опоры А). Покажите эту силу на схеме.
3. Составьте уравнения равновесия:
   - Сумма проекций всех сил на горизонтальную ось X: ΣF_x = 0 → найдите R_Ax.
   - Сумма моментов всех сил относительно опоры А: ΣM_A = 0 → найдите R_B.
   - Сумма моментов всех сил относительно опоры В: ΣM_B = 0 → найдите R_Ay.
   (Или используйте уравнение суммы проекций на вертикальную ось Y: ΣF_y = 0 → проверьте R_Ay.)
4. Запишите найденные значения реакций: R_Ax, R_Ay, R_B (в кН). Укажите направления (если значение отрицательное — реакция направлена в противоположную сторону).
5. Выполните проверку: составьте уравнение ΣF_y = 0 (сумма всех вертикальных сил, включая реакции, должна быть равна нулю). Убедитесь, что проверка сходится (допускается расхождение до 0,01 кН из-за округления).
6. Сделайте вывод (1–2 предложения): какая из опор воспринимает большую нагрузку и почему.

--------------------------------------------------
ЗАДАНИЕ 2. ПОСТРОЕНИЕ ЭПЮР (ДЛЯ САМОПРОВЕРКИ)
--------------------------------------------------
Требуется (по желанию, для дополнительной проверки):
1. Постройте эпюру поперечных сил Q (качественно, без точных значений) для проверки правильности найденных реакций: эпюра должна начинаться со значения R_Ay, изменяться скачком в точке С (на величину P), затем линейно убывать на участке СВ (за счет q) и заканчиваться значением -R_B (скачок на опоре В).
2. Постройте эпюру изгибающих моментов M_изг (качественно): на участке АС — линейная, на участке СВ — парабола. Убедитесь, что эпюра заканчивается нулем на опоре В.

--------------------------------------------------
ТРЕБОВАНИЯ К ОТЧЕТУ И КРИТЕРИИ ОЦЕНКИ:
--------------------------------------------------
Преподаватель проверяет работу по следующим критериям:
- Оценка «5» (отлично): Правильно начерчена схема, верно составлены уравнения равновесия, верно найдены все реакции (совпадают с эталоном преподавателя), проверка сходится. Сделан правильный вывод. Эпюры (если построены) соответствуют найденным реакциям.
- Оценка «4» (хорошо): Схема и уравнения составлены верно, но допущена одна арифметическая ошибка в расчетах (например, при вычислении сосредоточенной силы Q или момента от распределенной нагрузки), которая не повлияла на общий вывод. Проверка сходится с учетом ошибки.
- Оценка «3» (удовлетворительно): Верно начерчена схема и составлены уравнения, но допущены ошибки в решении системы (перепутаны знаки или неверно определены плечи сил). Проверка не сходится. Вывод отсутствует или сформулирован нечетко.
- Оценка «2» (неудовлетворительно): Студент не понимает метод составления уравнений равновесия, реакции определены неверно, схема отсутствует или выполнена хаотично. Проверка не выполнена. Студент не может объяснить, чем отличается шарнирно-подвижная опора от шарнирно-неподвижной.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- P = 10 + 10 = 20 кН.
- q = 2 + 2,5 = 4,5 кН/м.
- M = 5 + 5 = 10 кН·м.
- l1 = 2 + 0,5 = 2,5 м.
- l2 = 3 + 1,0 = 4,0 м.
- L = 2,5 + 4,0 = 6,5 м.
- Q = q * l2 = 4,5 * 4,0 = 18 кН.
- Точка приложения Q: на расстоянии l1 + l2/2 = 2,5 + 2,0 = 4,5 м от опоры А.
Уравнения:
ΣF_x = 0 → R_Ax = 0.
ΣM_A = 0: -P * l1 - Q * (l1 + l2/2) - M + R_B * L = 0 → -20 * 2,5 - 18 * 4,5 - 10 + R_B * 6,5 = 0 → -50 - 81 - 10 + 6,5 * R_B = 0 → 6,5 * R_B = 141 → R_B = 21,69 кН.
ΣF_y = 0: R_Ay - P - Q + R_B = 0 → R_Ay = 20 + 18 - 21,69 = 16,31 кН.
Проверка: ΣM_B = 0: -R_Ay * L + P * (L - l1) + Q * (L - (l1 + l2/2)) + M = 0 → -16,31 * 6,5 + 20 * 4,0 + 18 * 2,0 + 10 = -106,015 + 80 + 36 + 10 = 19,985 ≈ 20 (небольшое расхождение из-за округления, допустимо). Или проверьте сумму вертикальных сил: 16,31 - 20 - 18 + 21,69 = 0 (сходится).
Подставляйте свои числа и приступайте к решению. Удачи!
