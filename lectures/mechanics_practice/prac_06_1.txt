ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 6 (часть 1)
Тема: Решение задач на поступательное и вращательное движения: кинематика точки

Цель работы: Формирование умений определять кинематические характеристики точки (траекторию, скорость, ускорение) при поступательном и вращательном движениях, а также строить графики движения.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите расчетную схему (от руки, с соблюдением масштаба и пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

---

ЗАДАНИЕ 1. КИНЕМАТИКА ТОЧКИ ПРИ ПОСТУПАТЕЛЬНОМ ДВИЖЕНИИ
---
Точка движется прямолинейно по закону: S(t) = A*t^2 + B*t + C, где:
- A = 0,5 + 0,1*N (м/с²) — ускорение;
- B = 2 + 0,5*N (м/с) — начальная скорость;
- C = 1 + 0,2*N (м) — начальное положение.
(N — ваш номер по журналу.)

Что необходимо сделать:
1. Запишите уравнение движения S(t) с вашими числовыми коэффициентами.
2. Определите скорость точки как производную от пути по времени: v(t) = dS/dt = 2*A*t + B. Запишите уравнение v(t) с числовыми коэффициентами.
3. Определите ускорение точки как производную от скорости по времени: a(t) = dv/dt = 2*A. Запишите значение ускорения (оно постоянно).
4. Рассчитайте скорость и ускорение в момент времени t = 2 с (подставьте t = 2 в уравнения v(t) и a(t)). Запишите результаты.
5. Постройте график скорости v(t) для интервала времени от 0 до 5 с (качественно, от руки). Отметьте на графике значение v при t = 2 с.
6. Сделайте вывод (1–2 предложения): как изменяется скорость точки с течением времени (если A > 0, скорость растет; если A < 0, скорость убывает; ускорение постоянно).

---

ЗАДАНИЕ 2. КИНЕМАТИКА ТОЧКИ ПРИ ВРАЩАТЕЛЬНОМ ДВИЖЕНИИ
---
Точка движется по окружности радиусом R = 0,5 + 0,1*N м (где N — ваш номер по журналу) с угловым ускорением ε = 2 + 0,5*N рад/с². Начальная угловая скорость ω0 = 0 (движение начинается из состояния покоя).

Что необходимо сделать:
1. Запишите уравнение угловой скорости: ω(t) = ω0 + ε*t = ε*t. Запишите уравнение с числовыми коэффициентами.
2. Запишите уравнение угла поворота: φ(t) = ω0*t + (ε*t²)/2 = (ε*t²)/2. Запишите уравнение с числовыми коэффициентами.
3. Рассчитайте угловую скорость и угол поворота в момент времени t = 3 с (подставьте t = 3 в уравнения ω(t) и φ(t)). Запишите результаты.
4. Рассчитайте линейную скорость точки по формуле: v = ω * R. Используйте значение ω при t = 3 с. Ответ получите в м/с.
5. Рассчитайте нормальное (центростремительное) ускорение точки по формуле: a_n = ω² * R. Используйте значение ω при t = 3 с. Ответ получите в м/с².
6. Рассчитайте касательное ускорение точки по формуле: a_τ = ε * R. Ответ получите в м/с².
7. Рассчитайте полное ускорение точки по формуле: a = √(a_n² + a_τ²). Ответ получите в м/с² (округлите до двух знаков).
8. Начертите схему: окружность радиуса R, точку на окружности (положение точки при t = 3 с), вектор линейной скорости v (по касательной к окружности), вектор нормального ускорения a_n (к центру окружности), вектор касательного ускорения a_τ (по касательной в сторону движения). Подпишите все векторы.
9. Сделайте вывод (1–2 предложения): как изменяется линейная скорость точки с течением времени (при постоянном угловом ускорении линейная скорость растет пропорционально времени).

---
Преподаватель проверяет работу по следующим критериям:

Верно рассчитаны угловая скорость, угол поворота, линейная скорость, нормальное и касательное ускорения для вращательного движения. Схема выполнена с соблюдением пропорций, все векторы показаны верно. Сделаны правильные выводы.
- Оценка «4» (хорошо): Все расчеты выполнены верно, но допущена одна арифметическая ошибка (например, при подстановке t = 2 или t = 3), которая не повлияла на общий вывод. График или схема выполнены, но один из элементов не подписан.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- A = 0,5 + 0,5 = 1,0 м/с².
- B = 2 + 2,5 = 4,5 м/с.
- C = 1 + 1,0 = 2,0 м.
- Уравнение движения: S(t) = 1,0*t² + 4,5*t + 2,0.
- Скорость: v(t) = 2*1,0*t + 4,5 = 2,0*t + 4,5.
- Ускорение: a(t) = 2,0 м/с².
- При t = 2 с: v(2) = 2,0*2 + 4,5 = 8,5 м/с; a = 2,0 м/с².
- R = 0,5 + 0,5 = 1,0 м.
- ε = 2 + 2,5 = 4,5 рад/с².
- ω(t) = 4,5*t.
- φ(t) = (4,5*t²)/2 = 2,25*t².
- При t = 3 с: ω(3) = 4,5*3 = 13,5 рад/с; φ(3) = 2,25*9 = 20,25 рад.
- v = 13,5 * 1,0 = 13,5 м/с.
- a_n = 13,5² * 1,0 = 182,25 м/с².
- a_τ = 4,5 * 1,0 = 4,5 м/с².
- a = √(182,25² + 4,5²) ≈ 182,3 м/с².
Подставляйте свои числа и приступайте к решению. Удачи!
