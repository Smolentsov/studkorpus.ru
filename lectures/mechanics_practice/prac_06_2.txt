ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 6 (часть 2)
Тема: Решение задач на поступательное и вращательное движения: твердое тело

Цель работы: Формирование умений определять кинематические характеристики твердого тела при поступательном и вращательном движениях (скорости и ускорения точек тела, угловые скорости и ускорения), а также строить кинематические схемы механизмов.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, циркуль, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите расчетную схему (от руки, с соблюдением масштаба и пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

---

ЗАДАНИЕ 1. ПОСТУПАТЕЛЬНОЕ ДВИЖЕНИЕ ТВЕРДОГО ТЕЛА
---
Твердое тело (например, кузов автомобиля или платформа) движется поступательно прямолинейно. Уравнение движения тела: S(t) = A*t^2 + B*t + C, где:
- A = 0,8 + 0,2*N (м/с²) — ускорение;
- B = 3 + 0,5*N (м/с) — начальная скорость;
- C = 2 + 0,3*N (м) — начальное положение.
(N — ваш номер по журналу.)

Что необходимо сделать:
1. Запишите уравнение движения S(t) с вашими числовыми коэффициентами.
2. Определите скорость тела: v(t) = dS/dt = 2*A*t + B. Запишите уравнение v(t).
3. Определите ускорение тела: a(t) = dv/dt = 2*A. Запишите значение ускорения (оно постоянно).
4. Рассчитайте скорость и ускорение в момент времени t = 3 с (подставьте t = 3 в уравнения). Запишите результаты.
5. Постройте график скорости v(t) для интервала времени от 0 до 5 с (качественно, от руки). Отметьте на графике значение v при t = 3 с.
6. Сделайте вывод (1–2 предложения): как изменяется скорость тела с течением времени (если A > 0, скорость растет; ускорение постоянно). При поступательном движении все точки тела имеют одинаковые скорости и ускорения.

---

ЗАДАНИЕ 2. ВРАЩАТЕЛЬНОЕ ДВИЖЕНИЕ ТВЕРДОГО ТЕЛА
---
Твердое тело (например, вал электродвигателя, колесо) вращается вокруг неподвижной оси. Уравнение вращательного движения: φ(t) = A*t^2 + B*t + C, где:
- A = 0,5 + 0,1*N (рад/с²) — угловое ускорение (удвоенное);
- B = 2 + 0,5*N (рад/с) — начальная угловая скорость;
- C = 1 + 0,2*N (рад) — начальный угол поворота.
(N — ваш номер по журналу.)

Что необходимо сделать:
1. Запишите уравнение вращательного движения φ(t) с вашими числовыми коэффициентами.
2. Определите угловую скорость тела: ω(t) = dφ/dt = 2*A*t + B. Запишите уравнение ω(t).
3. Определите угловое ускорение тела: ε(t) = dω/dt = 2*A. Запишите значение углового ускорения (оно постоянно).
4. Рассчитайте угловую скорость и угловое ускорение в момент времени t = 2 с (подставьте t = 2 в уравнения). Запишите результаты.
5. Рассчитайте линейную скорость точки, находящейся на расстоянии R = 0,3 + 0,1*N м от оси вращения, в момент времени t = 2 с по формуле: v = ω * R. Ответ получите в м/с.
6. Рассчитайте нормальное ускорение этой точки по формуле: a_n = ω² * R. Ответ получите в м/с².
7. Рассчитайте касательное ускорение этой точки по формуле: a_τ = ε * R. Ответ получите в м/с².
8. Начертите схему: окружность радиуса R, точку на окружности (положение точки при t = 2 с), вектор линейной скорости v (по касательной к окружности), вектор нормального ускорения a_n (к центру окружности), вектор касательного ускорения a_τ (по касательной в сторону движения). Подпишите все векторы.
9. Сделайте вывод (1–2 предложения): как изменяется линейная скорость точки с течением времени (при постоянном угловом ускорении линейная скорость растет пропорционально времени).

ЗАДАНИЕ 3. КИНЕМАТИЧЕСКАЯ СХЕМА МЕХАНИЗМА (ПО ВАРИАНТАМ)
---
Для заданного механизма (по варианту) необходимо определить скорости и ускорения точек, а также построить кинематическую схему.

Описание механизма (для всех вариантов):
- Кривошип OA вращается с постоянной угловой скоростью ω_OA = 2 + 0,5*N рад/с (где N — ваш номер по журналу).
- Длина кривошипа OA = 0,2 + 0,05*N м.
- Шатун AB соединяет точку A с ползуном B. Длина шатуна AB = 0,5 + 0,1*N м.
- Ползун B движется горизонтально (по направляющей).
- Угол поворота кривошипа в данный момент: φ = 30° + 10°*N (например, при N=5: φ = 80°).

Что необходимо сделать:
1. Начертите кинематическую схему механизма: покажите кривошип OA (под углом φ к горизонту), шатун AB, ползун B на горизонтальной направляющей. Обозначьте точки O, A, B.
2. Определите скорость точки A: v_A = ω_OA * OA (в м/с). Вектор v_A направлен перпендикулярно кривошипу OA (по касательной к окружности, которую описывает точка A).
3. Определите скорость точки B (ползуна). Для этого используйте метод проекций (или план скоростей): скорость точки B направлена горизонтально. Скорость точки A можно разложить на две составляющие: вдоль шатуна AB и перпендикулярно ему. Из условия, что проекция скорости точки A на направление шатуна AB равна проекции скорости точки B на то же направление, найдите v_B.
   Формула для учебного расчета: v_B = v_A * cos(φ) / cos(β), где β — угол наклона шатуна AB к горизонту (определите из геометрии: sin(β) = (OA * sin(φ)) / AB).
4. Определите угловую скорость шатуна AB: ω_AB = (v_A * sin(φ - β)) / AB (или используйте формулу ω_AB = v_A_perp / AB, где v_A_perp — перпендикулярная составляющая скорости точки A относительно точки B). Округлите до двух знаков.
5. Определите ускорение точки A: a_A = ω_OA² * OA (нормальное ускорение, направлено к центру вращения O). Касательное ускорение равно нулю (ω_OA = const).
6. Определите ускорение точки B (ползуна). Для учебного расчета используйте приближенную формулу: a_B ≈ a_A * cos(φ) (без учета углового ускорения шатуна). Округлите до двух знаков.
7. Начертите на схеме векторы скоростей v_A и v_B, а также векторы ускорений a_A и a_B (качественно, с указанием направлений).
8. Сделайте вывод (1–2 предложения): как скорость ползуна B зависит от угла поворота кривошипа (при φ = 0° или 180° скорость ползуна максимальна/минимальна; при φ = 90° скорость ползуна равна скорости точки A).

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- A = 0,8 + 1,0 = 1,8 м/с²; B = 3 + 2,5 = 5,5 м/с; C = 2 + 1,5 = 3,5 м.
- S(t) = 1,8*t² + 5,5*t + 3,5.
- v(t) = 3,6*t + 5,5; a = 3,6 м/с².
- При t = 3 с: v(3) = 3,6*3 + 5,5 = 16,3 м/с; a = 3,6 м/с².
- A_вращ = 0,5 + 0,5 = 1,0 рад/с²; B_вращ = 2 + 2,5 = 4,5 рад/с; C_вращ = 1 + 1,0 = 2,0 рад.
- φ(t) = 1,0*t² + 4,5*t + 2,0.
- ω(t) = 2,0*t + 4,5; ε = 2,0 рад/с².
- При t = 2 с: ω(2) = 2,0*2 + 4,5 = 8,5 рад/с; ε = 2,0 рад/с².
- R = 0,3 + 0,5 = 0,8 м.
- v = 8,5 * 0,8 = 6,8 м/с.
- a_n = 8,5² * 0,8 = 72,25 * 0,8 = 57,8 м/с².
- a_τ = 2,0 * 0,8 = 1,6 м/с².
- ω_OA = 2 + 2,5 = 4,5 рад/с.
- OA = 0,2 + 0,25 = 0,45 м.
- AB = 0,5 + 0,5 = 1,0 м.
- φ = 30° + 50° = 80°.
- v_A = 4,5 * 0,45 = 2,025 м/с.
- sin(β) = (0,45 * sin(80°)) / 1,0 = (0,45 * 0,9848) / 1,0 = 0,4432 → β ≈ 26,3°.
- v_B = 2,025 * cos(80°) / cos(26,3°) = 2,025 * 0,1736 / 0,8968 ≈ 0,392 м/с.
- ω_AB = (2,025 * sin(80° - 26,3°)) / 1,0 = 2,025 * sin(53,7°) / 1,0 = 2,025 * 0,806 ≈ 1,63 рад/с.

- a_B ≈ 9,11 * cos(80°) = 9,11 * 0,1736 ≈ 1,58 м/с².
