ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 16
Тема: Расчет подшипников качения

Цель работы: Формирование умений определять эквивалентную динамическую нагрузку на подшипник, рассчитывать долговечность (ресурс) подшипника качения и подбирать подшипник по каталогу.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, калькулятор, конспект лекций, справочные таблицы (каталог подшипников качения).

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите эскиз подшипника (от руки, с соблюдением пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. РАСЧЕТ ЭКВИВАЛЕНТНОЙ НАГРУЗКИ И ДОЛГОВЕЧНОСТИ
--------------------------------------------------
Вал редуктора установлен на двух шариковых радиальных однорядных подшипниках. Требуется рассчитать долговечность наиболее нагруженного подшипника и проверить, подходит ли он для заданных условий работы.

Исходные данные для расчета:
- Радиальная нагрузка на подшипник (наиболее нагруженный): F_r = (N + 5) кН (где N — ваш номер по журналу).
- Осевая нагрузка на подшипник: F_a = 0,2 * F_r кН (для учебного расчета примем, что осевая нагрузка составляет 20% от радиальной).
- Частота вращения вала: n = 1000 + 50*N об/мин.
- Требуемая долговечность подшипника (ресурс): L_треб = 10000 + 1000*N часов.
- Подшипник шариковый радиальный однорядный, серия средняя, условное обозначение: 200 + N (например, при N=5: подшипник №205).
- Грузоподъемность подшипника (из каталога, примем для учебного расчета):
  - Динамическая грузоподъемность: C = 20 + 2*N кН.
  - Статическая грузоподъемность: C_0 = 10 + N кН.
- Коэффициент вращения: V = 1 (вращается внутреннее кольцо).
- Коэффициент безопасности: K_б = 1,2 (умеренные толчки).
- Температурный коэффициент: K_т = 1,0 (рабочая температура до 100°C).
- Коэффициент осевого нагружения: e = 0,3 (принято для учебного расчета).
- Коэффициент влияния осевого нагружения: Y = 1,5 (принято для учебного расчета).
- Показатель степени для шарикоподшипников: p = 3.

Что необходимо сделать:
1. Определите отношение F_a / (V * F_r). Сравните его с коэффициентом e = 0,3.
2. Если F_a / (V * F_r) ≤ e, то эквивалентная динамическая нагрузка рассчитывается по формуле: P = V * F_r * K_б * K_т.
   Если F_a / (V * F_r) > e, то P = (X * V * F_r + Y * F_a) * K_б * K_т, где X = 0,56 (коэффициент радиальной нагрузки для шариковых подшипников).
3. Рассчитайте эквивалентную динамическую нагрузку P (в кН).
4. Рассчитайте требуемую динамическую грузоподъемность (C_треб) по формуле:
   C_треб = P * (L_треб / (10^6 / (60 * n)))^(1/p) — используйте упрощенную формулу для учебного расчета: C_треб = P * (L_треб * 60 * n / 10^6)^(1/3), где L_треб — в часах, n — в об/мин. Ответ получите в кН.
5. Сравните C_треб с паспортной динамической грузоподъемностью C (из исходных данных). Если C ≥ C_треб, подшипник подходит. Если C < C_треб, подшипник не подходит (нужно выбрать другой типоразмер).
6. Сделайте вывод (1–2 предложения): подходит ли выбранный подшипник для заданных условий работы. Если нет, укажите, какой параметр нужно изменить (например, выбрать подшипник более тяжелой серии или увеличить его размеры).

--------------------------------------------------
ЗАДАНИЕ 2. ПОСТРОЕНИЕ ЭСКИЗА ПОДШИПНИКА
--------------------------------------------------
Требуется:
1. Начертите эскиз шарикового радиального однорядного подшипника (вид в разрезе или сбоку) с указанием основных элементов:
   - Наружное кольцо (сплошная линия);
   - Внутреннее кольцо (сплошная линия);
   - Шарики (окружности) между кольцами;
   - Сепаратор (пунктирная линия или условное обозначение).
2. Подпишите все элементы на эскизе: «наружное кольцо», «внутреннее кольцо», «шарик», «сепаратор».
3. Покажите на эскизе радиальную нагрузку F_r в виде стрелки, направленной к центру подшипника, и осевую нагрузку F_a в виде стрелки, направленной вдоль оси вала.
4. Напишите вывод (1–2 предложения): почему шариковые радиальные подшипники не рекомендуется применять при больших осевых нагрузках (они плохо воспринимают осевые нагрузки, для этого применяют радиально-упорные или упорные подшипники).

ТРЕБОВАНИЯ К ОТЧЕТУ И КРИТЕРИИ ОЦЕНКИ:
--------------------------------------------------
Преподаватель проверяет работу по следующим критериям:
- Оценка «5» (отлично): Верно рассчитана эквивалентная динамическая нагрузка, верно определена требуемая грузоподъемность и сделан правильный вывод о пригодности подшипника. Эскиз подшипника выполнен с соблюдением пропорций, все элементы подписаны, силы показаны верно. Сделан правильный вывод о применении подшипников.
- Оценка «4» (хорошо): Все расчеты выполнены верно, но допущена одна арифметическая ошибка (например, при переводе единиц или округлении), которая не повлияла на общий вывод. Эскиз выполнен, но один из элементов не подписан или сила показана неверно.
- Оценка «3» (удовлетворительно): Верно найдена эквивалентная нагрузка, но допущены ошибки в расчете требуемой грузоподъемности (перепутаны формулы или показатели степени). Эскиз выполнен схематично, без указания части элементов. Вывод отсутствует или сформулирован нечетко.
- Оценка «2» (неудовлетворительно): Студент не понимает методику расчета подшипников, эквивалентная нагрузка и грузоподъемность рассчитаны неверно, эскиз отсутствует или выполнен хаотично. Студент не может объяснить, что такое динамическая грузоподъемность и долговечность подшипника.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- F_r = 5 + 5 = 10 кН.
- F_a = 0,2 * 10 = 2 кН.
- n = 1000 + 50*5 = 1250 об/мин.
- L_треб = 10000 + 1000*5 = 15000 часов.
- Подшипник № 205.
- C = 20 + 2*5 = 30 кН.
- C_0 = 10 + 5 = 15 кН.
- F_a / (V * F_r) = 2 / (1 * 10) = 0,2 ≤ e = 0,3. Следовательно, осевая нагрузка не влияет на эквивалентную нагрузку.
- P = V * F_r * K_б * K_т = 1 * 10 * 1,2 * 1,0 = 12 кН.
- C_треб = 12 * (15000 * 60 * 1250 / 10^6)^(1/3) = 12 * (1125000000 / 1000000)^(1/3) = 12 * (1125)^(1/3) = 12 * 10,4 ≈ 124,8 кН.
- Сравниваем: C = 30 кН < C_треб = 124,8 кН. Подшипник № 205 не подходит! Нужно выбрать подшипник с большей грузоподъемностью (например, более тяжелой серии или большего диаметра).
