ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 5 (часть 1)
Тема: Определение центра тяжести стандартных прокатных профилей: расчет координат

Цель работы: Формирование умений определять координаты центра тяжести сложного сечения, составленного из стандартных прокатных профилей (уголков, швеллеров, двутавров, полос), используя справочные таблицы сортаментов.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, калькулятор, конспект лекций, справочные таблицы (сортамент прокатных профилей: ГОСТ 8509-93, ГОСТ 8240-97, ГОСТ 8239-89).

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите расчетную схему сечения (от руки, с соблюдением масштаба и пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

---

ЗАДАНИЕ 1. ОПРЕДЕЛЕНИЕ КООРДИНАТ ЦЕНТРА ТЯЖЕСТИ СЛОЖНОГО СЕЧЕНИЯ
---
Сложное сечение состоит из трех стандартных прокатных профилей:
1. Двутавр № (10 + N) (где N — ваш номер по журналу).
2. Швеллер № (8 + N).
3. Уголок равнополочный № (5 + N).

Взаимное расположение профилей (начертите схему):
- Двутавр расположен горизонтально (полка параллельна оси X), его центр тяжести находится в точке с координатами (x1; y1).
- Швеллер расположен вертикально (полка параллельна оси Y), его центр тяжести находится в точке с координатами (x2; y2).
- Уголок расположен в правом верхнем углу, его центр тяжести находится в точке с координатами (x3; y3).

Для учебного расчета примем следующие координаты центров тяжести профилей (в см):
- Двутавр: x1 = 0; y1 = 0 (начало координат — центр тяжести двутавра).
- Швеллер: x2 = 10 + N; y2 = 0 (швеллер расположен справа от двутавра, на той же горизонтальной оси).
- Уголок: x3 = 10 + N; y3 = 10 + N (уголок расположен над швеллером, в правом верхнем углу).

Что необходимо сделать:
1. Начертите схему сложного сечения: покажите три профиля (двутавр, швеллер, уголок), оси X и Y, а также координаты центров тяжести каждого профиля (x1, y1), (x2, y2), (x3, y3). Соблюдайте пропорции (примерно).
2. По справочным таблицам (сортаменту) выпишите для каждого профиля:
   - Площадь поперечного сечения (A_i) в см².
   - Координаты центра тяжести (x_i, y_i) в см (из условия).
   (Например, для двутавра № 15: A = 18,2 см²; для швеллера № 13: A = 15,6 см²; для уголка № 10: A = 15,5 см². Значения возьмите из сортамента для своих номеров профилей.)
3. Рассчитайте координаты центра тяжести всего сложного сечения (X_C, Y_C) по формулам:
   X_C = (A1*x1 + A2*x2 + A3*x3) / (A1 + A2 + A3)
   Y_C = (A1*y1 + A2*y2 + A3*y3) / (A1 + A2 + A3)
   Округлите до двух знаков после запятой.
4. Нанесите найденный центр тяжести (точку C) на схему сечения и подпишите его координаты (X_C, Y_C).
5. Сделайте вывод (1–2 предложения): как расположение профилей влияет на положение центра тяжести всего сечения (если профили расположены симметрично, центр тяжести может лежать на оси симметрии; в данном случае сечение несимметрично, поэтому центр тяжести смещен в сторону более тяжелого профиля).

---

ЗАДАНИЕ 2. ПРОВЕРКА ПРАВИЛЬНОСТИ РАСЧЕТА
---
Требуется:
1. Проверьте правильность расчета, используя метод моментов площадей: сумма моментов площадей профилей относительно найденного центра тяжести должна быть равна нулю (с учетом знаков).
   Σ(A_i * (x_i - X_C)) = 0
   Σ(A_i * (y_i - Y_C)) = 0
2. Подставьте полученные значения и убедитесь, что сумма близка к нулю (допускается расхождение до 0,1 см³ из-за округления).
3. Запишите проверку в работу.

---

ТРЕБОВАНИЯ К ОТЧЕТУ И КРИТЕРИИ ОЦЕНКИ:
---
Преподаватель проверяет работу по следующим критериям:
- Оценка «5» (отлично): Правильно начерчена схема сечения, верно выписаны площади и координаты профилей из сортамента, верно рассчитаны координаты центра тяжести (X_C, Y_C) (совпадают с эталоном преподавателя), проверка сходится. Сделан правильный вывод.
- Оценка «4» (хорошо): Схема и расчеты выполнены верно, но допущена одна арифметическая ошибка (например, при выписке площади из сортамента или при вычислении X_C), которая не повлияла на общий вывод. Проверка сходится с учетом ошибки.
- Оценка «3» (удовлетворительно): Верно начерчена схема и выписаны площади, но допущены ошибки в расчете координат (перепутаны формулы или неверно подставлены координаты центров тяжести профилей). Проверка не сходится. Вывод отсутствует или сформулирован нечетко.
- Оценка «2» (неудовлетворительно): Студент не понимает метод определения центра тяжести сложного сечения, координаты рассчитаны неверно, схема отсутствует или выполнена хаотично. Проверка не выполнена. Студент не может объяснить, что такое центр тяжести и как его найти для сложного сечения.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- Двутавр № 15: A1 = 18,2 см²; x1 = 0; y1 = 0.
- Швеллер № 13: A2 = 15,6 см²; x2 = 10 + 5 = 15 см; y2 = 0.
- Уголок № 10: A3 = 15,5 см²; x3 = 15 см; y3 = 15 см.
X_C = (18,2*0 + 15,6*15 + 15,5*15) / (18,2 + 15,6 + 15,5) = (0 + 234 + 232,5) / 49,3 = 466,5 / 49,3 ≈ 9,46 см.
Y_C = (18,2*0 + 15,6*0 + 15,5*15) / 49,3 = 232,5 / 49,3 ≈ 4,72 см.
Проверка: Σ(A_i * (x_i - X_C)) = 18,2*(0 - 9,46) + 15,6*(15 - 9,46) + 15,5*(15 - 9,46) = 18,2*(-9,46) + 15,6*5,54 + 15,5*5,54 = -172,17 + 86,42 + 85,87 = 0,12 ≈ 0 (сходится).
Σ(A_i * (y_i - Y_C)) = 18,2*(0 - 4,72) + 15,6*(0 - 4,72) + 15,5*(15 - 4,72) = 18,2*(-4,72) + 15,6*(-4,72) + 15,5*10,28 = -85,9 - 73,63 + 159,34 = -0,19 ≈ 0 (сходится).
Подставляйте свои числа и приступайте к решению. Удачи!
