ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 11
Тема: Определение рациональных сечений вала

Цель работы: Формирование умений анализировать напряженное состояние вала при кручении, сравнивать различные формы поперечных сечений (сплошное, кольцевое) и выбирать наиболее рациональный профиль с точки зрения металлоемкости и прочности.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите эскизы сечений (от руки, с соблюдением пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. РАСЧЕТ СПЛОШНОГО СЕЧЕНИЯ ВАЛА
--------------------------------------------------
Вал передает крутящий момент M_кр = 4*N кН·м (где N — ваш номер по журналу). Материал вала — сталь 40Х, допускаемое касательное напряжение [τ] = 45 МПа.

Требуется:
1. Из условия прочности при кручении определите требуемый диаметр сплошного вала (d_сплош) по формуле: d_сплош ≥ (16 * M_кр / (π * [τ]))^(1/3). Ответ получите в метрах, переведите в миллиметры и округлите до целого числа (в большую сторону).
2. Начертите эскиз поперечного сечения сплошного вала (круг) с найденным диаметром. Укажите размер на чертеже.
3. Вычислите площадь поперечного сечения сплошного вала (A_сплош) в см².
4. Вычислите полярный момент сопротивления (W_p_сплош) для сплошного вала по формуле: W_p = π * d^3 / 16. Ответ получите в см³ (округлите до сотых).

--------------------------------------------------
ЗАДАНИЕ 2. РАСЧЕТ КОЛЬЦЕВОГО СЕЧЕНИЯ ВАЛА
--------------------------------------------------
Для передачи того же крутящего момента M_кр = 4*N кН·м решено использовать полый (кольцевой) вал с соотношением внутреннего и внешнего диаметров: d_вн / d_нар = 0,7 (где d_вн — внутренний диаметр, d_нар — наружный диаметр).

Требуется:
1. Из условия прочности при кручении определите требуемый наружный диаметр полого вала (d_нар) по формуле: d_нар ≥ (16 * M_кр / (π * (1 - (d_вн/d_нар)^4) * [τ]))^(1/3). Ответ получите в метрах, переведите в миллиметры и округлите до целого числа (в большую сторону).
2. Определите внутренний диаметр полого вала: d_вн = 0,7 * d_нар (округлите до целого числа).
3. Начертите эскиз поперечного сечения полого вала (кольцо) с найденными наружным и внутренним диаметрами. Укажите размеры на чертеже.
4. Вычислите площадь поперечного сечения полого вала (A_полый) в см² по формуле: A_полый = π * (d_нар^2 - d_вн^2) / 4.
5. Вычислите полярный момент сопротивления (W_p_полый) для полого вала по формуле: W_p = π * d_нар^3 * (1 - (d_вн/d_нар)^4) / 16. Ответ получите в см³ (округлите до сотых).

--------------------------------------------------
ЗАДАНИЕ 3. СРАВНЕНИЕ ЭФФЕКТИВНОСТИ СЕЧЕНИЙ
--------------------------------------------------
На основе расчетов из Заданий 1 и 2 сравните два типа сечений.

Требуется:
1. Определите, насколько площадь полого вала меньше площади сплошного (в процентах) по формуле: ΔA = (A_сплош - A_полый) / A_сплош * 100%. Округлите до целого числа.
2. Определите, насколько наружный диаметр полого вала больше диаметра сплошного (в процентах) по формуле: Δd = (d_нар - d_сплош) / d_сплош * 100%. Округлите до целого числа.
3. Сделайте вывод (2–3 предложения): какой вал выгоднее применять с точки зрения экономии металла и почему. Учтите, что при одинаковой прочности полый вал имеет меньшую массу, но больший наружный диаметр, что может быть ограничением по габаритам.

--------------------------------------------------
ТРЕБОВАНИЯ К ОТЧЕТУ И КРИТЕРИИ ОЦЕНКИ:
--------------------------------------------------
Преподаватель проверяет работу по следующим критериям:
- Оценка «5» (отлично): Верно рассчитаны диаметры и характеристики для сплошного и полого сечений (совпадают с эталоном преподавателя), начерчены оба эскиза с размерами, правильно вычислены площади и моменты сопротивления. Верно рассчитаны проценты ΔA и Δd, сделан обоснованный вывод о рациональности.
- Оценка «4» (хорошо): Все расчеты выполнены верно, но допущена одна арифметическая ошибка в вычислении площади или момента сопротивления (не влияющая на общий вывод). Или вывод сформулирован нечетко, но проценты рассчитаны верно.
- Оценка «3» (удовлетворительно): Верно найдены диаметры сплошного и полого валов, но эскизы выполнены без размеров или с нарушением пропорций. Допущены ошибки в расчете W_p (перепутаны формулы для круга и кольца). Сравнение выполнено частично (рассчитан только один процент).
- Оценка «2» (неудовлетворительно): Диаметры валов найдены неверно (ошибка в формуле или переводе единиц), эскизы отсутствуют. Сравнение не выполнено. Студент не может объяснить, в чем преимущество полого вала перед сплошным.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- M_кр = 20 кН·м = 20000 Н·м (или 20·10^6 Н·мм)
- d_сплош ≥ (16 * 20000 / (3,14 * 45·10^6))^(1/3) = (320000 / 141300000)^(1/3) = (0,00226)^(1/3) ≈ 0,131 м = 131 мм.
- Примите d_сплош = 131 мм (или 135 мм по стандартному ряду).
Далее подставляйте свои числа и приступайте к решению. Удачи!
