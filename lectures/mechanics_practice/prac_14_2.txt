ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 14 (часть 2)
Тема: Расчет основных геометрических характеристик червячных передач: силы и КПД

Цель работы: Формирование умений определять силы, действующие в червячном зацеплении (окружную, радиальную, осевую), а также рассчитывать коэффициент полезного действия (КПД) червячной передачи и строить расчетную схему нагружения валов.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите расчетную схему передачи (от руки, с соблюдением пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. РАСЧЕТ СИЛ В ЗАЦЕПЛЕНИИ
--------------------------------------------------
Червячная передача (из предыдущего занятия) передает крутящий момент с червяка на колесо.
Исходные данные для расчета (используйте результаты ПЗ №14, часть 1):
- Вращающий момент на валу червяка: T1 = (N + 15) Н·м (где N — ваш номер по журналу).
- Делительный диаметр червяка: d1 (из ПЗ №14, часть 1).
- Делительный диаметр колеса: d2 (из ПЗ №14, часть 1).
- Угол зацепления: α = 20° (стандартный угол).
- Угол подъема винтовой линии червяка: γ = arctg( z1 / q ) (где z1 — число заходов червяка, q — коэффициент диаметра червяка, из ПЗ №14, часть 1). Рассчитайте γ в градусах.

Что необходимо сделать:
1. Рассчитайте окружную силу на червяке (F_t1) по формуле: F_t1 = 2 * T1 / d1. Обратите внимание на размерности: T1 должно быть в Н·м, d1 — в м (переведите мм в м, разделив на 1000), чтобы получить силу в Ньютонах. Округлите до целого числа (Н). Эта же сила является осевой силой на колесе (F_a2 = F_t1).
2. Рассчитайте окружную силу на колесе (F_t2). Поскольку передача работает с передаточным числом u = z2 / z1, то F_t2 = F_t1 * η_предв * u (где η_предв — предварительное значение КПД, примем η_предв = 0,8 для учебного расчета). Округлите до целого числа (Н). Эта же сила является осевой силой на червяке (F_a1 = F_t2).
3. Рассчитайте радиальную силу в зацеплении (F_r) по формуле: F_r = F_t2 * tg(α). Округлите до целого числа (Н).
4. Проверьте: осевая сила на червяке F_a1 равна окружной силе на колесе F_t2, а осевая сила на колесе F_a2 равна окружной силе на червяке F_t1. Запишите это в работе.

--------------------------------------------------
ЗАДАНИЕ 2. РАСЧЕТ КПД ЧЕРВЯЧНОЙ ПЕРЕДАЧИ
--------------------------------------------------
Требуется:
1. Рассчитайте КПД червячной передачи (η) по формуле:
   η = tg(γ) / tg(γ + φ)
   где:
   - γ — угол подъема винтовой линии червяка (рассчитан в Задании 1);
   - φ — угол трения, который зависит от коэффициента трения f. Для учебного расчета примем f = 0,1, тогда φ = arctg(0,1) ≈ 5,71°.
2. Переведите углы γ и φ в радианы (или используйте калькулятор с функцией тангенса в градусах). Рассчитайте η. Округлите до сотых (например, 0,85).
3. Сравните полученное значение η с предварительным значением η_предв = 0,8. Сделайте вывод (1–2 предложения): соответствует ли фактический КПД предварительному значению. Если η < η_предв, укажите, какие потери (например, в зацеплении или в подшипниках) могли быть не учтены.
4. Рассчитайте мощность на выходном валу (P2), если мощность на входном валу P1 = T1 * ω1 (где ω1 — угловая скорость червяка, примем ω1 = 100 рад/с для учебного расчета). P1 = T1 * 100 (в Вт). P2 = P1 * η (в Вт). Запишите значения P1 и P2.

--------------------------------------------------
ЗАДАНИЕ 3. ПОСТРОЕНИЕ СХЕМЫ НАГРУЖЕНИЯ ВАЛОВ
--------------------------------------------------
Требуется:
1. Начертите схему червячной передачи (вид сбоку или сверху) с указанием вала червяка (вал 1) и вала колеса (вал 2), а также точки контакта витков червяка и зубьев колеса.
2. В точке контакта покажите векторы сил:
   - Для червяка: окружную силу F_t1 (направлена по касательной к делительной окружности червяка, против направления вращения червяка), радиальную силу F_r1 (направлена к оси червяка), осевую силу F_a1 (направлена вдоль оси червяка).
   - Для колеса: окружную силу F_t2 (направлена по касательной к делительной окружности колеса, по направлению вращения колеса), радиальную силу F_r2 (направлена к оси колеса), осевую силу F_a2 (направлена вдоль оси колеса).
3. Подпишите все векторы (F_t1, F_r1, F_a1, F_t2, F_r2, F_a2) и укажите их численные значения (из Задания 1) рядом с векторами.
4. Покажите на схеме направление вращения червяка (ω1) и колеса (ω2). Убедитесь, что направления вращения соответствуют направлению окружных сил.
5. Напишите вывод (1–2 предложения): как осевая сила на червяке влияет на работу подшипников вала червяка (осевая сила создает дополнительную нагрузку на подшипники, поэтому для червячных передач часто применяют конические или радиально-упорные подшипники).

--------------------------------------------------
ТРЕБОВАНИЯ К ОТЧЕТУ И КРИТЕРИИ ОЦЕНКИ:
--------------------------------------------------
Преподаватель проверяет работу по следующим критериям:
- Оценка «5» (отлично): Верно рассчитаны все силы в зацеплении (совпадают с эталоном преподавателя), верно рассчитан КПД и мощность на выходном валу. Схема нагружения выполнена с соблюдением пропорций, векторы сил направлены правильно, все значения подписаны, направления вращения указаны верно. Сделан правильный вывод.
- Оценка «4» (хорошо): Все расчеты выполнены верно, но допущена одна арифметическая ошибка в расчете силы или КПД (например, неверный перевод мм в м), которая не повлияла на общий характер схемы. Схема выполнена, но один из векторов подписан неверно или не указано направление вращения.
- Оценка «3» (удовлетворительно): Верно найдена окружная сила на червяке, но допущена ошибка в расчете окружной силы на колесе или радиальной силы. Схема выполнена схематично, без указания части векторов или их значений. Вывод отсутствует.
- Оценка «2» (неудовлетворительно): Студент не понимает, какие силы действуют в червячном зацеплении, расчеты выполнены неверно, схема отсутствует или выполнена хаотично. Студент не может объяснить, куда направлена осевая сила на червяке.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- T1 = 5 + 15 = 20 Н·м.
- d1 = 62,5 мм = 0,0625 м.
- d2 = 200 мм = 0,2 м.
- z1 = 2, q = 12,5 → γ = arctg(2 / 12,5) = arctg(0,16) ≈ 9,09°.
- F_t1 = 2 * 20 / 0,0625 = 40 / 0,0625 = 640 Н.
- u = z2 / z1 = 40 / 2 = 20.
- F_t2 = 640 * 0,8 * 20 = 10240 Н (округлим до 10240 Н).
- F_r = 10240 * tg(20°) = 10240 * 0,364 ≈ 3727 Н.
- φ ≈ 5,71°.
- η = tg(9,09°) / tg(9,09° + 5,71°) = 0,16 / tg(14,8°) = 0,16 / 0,264 ≈ 0,61.
- P1 = 20 * 100 = 2000 Вт = 2 кВт.
- P2 = 2000 * 0,61 = 1220 Вт = 1,22 кВт.
Подставляйте свои числа и приступайте к решению. Удачи!
