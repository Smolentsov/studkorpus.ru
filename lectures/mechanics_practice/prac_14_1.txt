ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 14 (часть 1)
Тема: Расчет основных геометрических характеристик червячных передач: геометрия

Цель работы: Формирование умений рассчитывать основные геометрические параметры червячной передачи (диаметры червяка и колеса, межосевое расстояние, число заходов червяка) и вычерчивать эскиз червячного зацепления.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, циркуль, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите эскиз зацепления (от руки, с соблюдением пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. РАСЧЕТ ГЕОМЕТРИЧЕСКИХ ПАРАМЕТРОВ ПЕРЕДАЧИ
--------------------------------------------------
Червячная передача состоит из червяка (ведущего звена) и червячного колеса (ведомого).
Исходные данные для расчета:
- Число заходов червяка: z1 = N mod 4 + 1 (где N — ваш номер по журналу, а mod — остаток от деления. Например, при N=5: 5 mod 4 = 1, тогда z1 = 2. Если N=8: 8 mod 4 = 0, тогда z1 = 1).
- Число зубьев червячного колеса: z2 = 30 + 2*N.
- Осевой модуль зацепления: m = 2 + 0,5*N мм (округлите до стандартного значения из ряда: 2; 2,5; 3; 4; 5; 6,3 мм. Например, при N=5 получаем m = 4,5 мм → принимаем m = 5 мм).
- Коэффициент диаметра червяка: q = 8 + N (округлите до стандартного значения из ряда: 8; 10; 12,5; 16; 20. Например, при N=5 получаем q = 13 → принимаем q = 12,5).

Что необходимо сделать:
1. Рассчитайте передаточное число передачи: u = z2 / z1. Округлите до сотых.
2. Рассчитайте основные геометрические параметры для червяка:
   - Делительный диаметр червяка: d1 = q * m (в мм).
   - Диаметр вершин витков червяка: d_a1 = d1 + 2*m (в мм).
   - Диаметр впадин витков червяка: d_f1 = d1 - 2,4*m (в мм).
   - Длина нарезанной части червяка: b1 = (11 + 0,06*z2) * m (в мм).
3. Рассчитайте основные геометрические параметры для червячного колеса:
   - Делительный диаметр колеса: d2 = m * z2 (в мм).
   - Диаметр вершин зубьев колеса: d_a2 = d2 + 2*m (в мм).
   - Диаметр впадин зубьев колеса: d_f2 = d2 - 2,4*m (в мм).
   - Наибольший диаметр колеса: d_ae2 = d_a2 + (6*m) / (z1 + 2) (в мм).
   - Ширина венца колеса: b2 = 0,75 * d_a1 (в мм).
4. Рассчитайте межосевое расстояние передачи: a_w = (d1 + d2) / 2 (в мм).
5. Проверьте условие: a_w = m * (q + z2) / 2. Результаты должны совпасть.

--------------------------------------------------
ЗАДАНИЕ 2. ПОСТРОЕНИЕ ЭСКИЗА ЧЕРВЯЧНОГО ЗАЦЕПЛЕНИЯ
--------------------------------------------------
Требуется:
1. Начертите эскиз червячной передачи (вид сбоку) в масштабе (например, 1:2 или 1:1, если позволяет лист). На эскизе изобразите:
   - Червяк (внизу) в виде цилиндра с указанием делительного диаметра d1, диаметра вершин d_a1 и длины нарезанной части b1.
   - Червячное колесо (вверху) в виде цилиндра (или сектора) с указанием делительного диаметра d2, диаметра вершин d_a2, наибольшего диаметра d_ae2 и ширины венца b2.
   - Покажите межосевое расстояние a_w (расстояние между осями червяка и колеса).
   - Укажите направление вращения червяка (например, по часовой стрелке, если смотреть с торца) и направление вращения колеса (против часовой стрелки).
2. Подпишите все размеры на эскизе (d1, d_a1, b1, d2, d_a2, d_ae2, b2, a_w).
3. Напишите вывод (1–2 предложения): как число заходов червяка z1 влияет на передаточное число u (при увеличении z1 передаточное число уменьшается, но передача становится быстрее).

ТРЕБОВАНИЯ К ОТЧЕТУ И КРИТЕРИИ ОЦЕНКИ:
--------------------------------------------------
Преподаватель проверяет работу по следующим критериям:
- Оценка «5» (отлично): Верно рассчитаны все геометрические параметры червяка и колеса (совпадают с эталоном преподавателя), верно найдено передаточное число и межосевое расстояние. Эскиз зацепления выполнен с соблюдением пропорций, все размеры подписаны, направления вращения указаны верно. Сделан правильный вывод.
- Оценка «4» (хорошо): Все расчеты выполнены верно, но допущена одна арифметическая ошибка (например, при округлении модуля или коэффициента q), которая не повлияла на общий результат. Эскиз выполнен, но один из размеров не подписан или нарушена пропорция (не влияющая на понимание).
- Оценка «3» (удовлетворительно): Верно найдены делительные диаметры и межосевое расстояние, но допущены ошибки в расчете диаметров вершин и впадин (перепутаны формулы). Эскиз выполнен схематично, без указания части размеров. Вывод отсутствует или сформулирован нечетко.
- Оценка «2» (неудовлетворительно): Студент не понимает геометрию червячной передачи, расчеты выполнены неверно (ошибки в формулах), эскиз отсутствует или выполнен хаотично. Студент не может объяснить, что такое число заходов червяка и делительный диаметр.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- z1 = 5 mod 4 + 1 = 1 + 1 = 2.
- z2 = 30 + 2*5 = 40.
- m = 2 + 0,5*5 = 4,5 мм → принимаем m = 5 мм (стандартное значение).
- q = 8 + 5 = 13 → принимаем q = 12,5 (стандартное значение).
- d1 = 12,5 * 5 = 62,5 мм.
- d_a1 = 62,5 + 2*5 = 72,5 мм.
- d_f1 = 62,5 - 2,4*5 = 50,5 мм.
- b1 = (11 + 0,06*40) * 5 = (11 + 2,4) * 5 = 13,4 * 5 = 67 мм.
- d2 = 5 * 40 = 200 мм.
- d_a2 = 200 + 2*5 = 210 мм.
- d_f2 = 200 - 2,4*5 = 188 мм.
- d_ae2 = 210 + (6*5) / (2 + 2) = 210 + 30 / 4 = 210 + 7,5 = 217,5 мм.
- b2 = 0,75 * 72,5 = 54,375 мм ≈ 54,4 мм.
- a_w = (62,5 + 200) / 2 = 131,25 мм.
Подставляйте свои числа и приступайте к решению. Удачи!
