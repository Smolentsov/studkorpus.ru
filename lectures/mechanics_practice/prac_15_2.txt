ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 15 (часть 2)
Тема: Расчет основных характеристик передач (по вариантам): цепные передачи

Цель работы: Формирование умений рассчитывать основные параметры цепной передачи (шаг цепи, число зубьев звездочек, межосевое расстояние, число звеньев цепи, передаточное число, окружную силу) и вычерчивать эскиз цепной передачи.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, циркуль, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите эскиз передачи (от руки, с соблюдением пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. РАСЧЕТ ГЕОМЕТРИЧЕСКИХ ПАРАМЕТРОВ ПЕРЕДАЧИ
--------------------------------------------------
Цепная передача состоит из ведущей звездочки (малой) и ведомой звездочки (большой), соединенных цепью.
Исходные данные для расчета:
- Число зубьев ведущей звездочки: z1 = 15 + N (где N — ваш номер по журналу). Округлите до целого числа (для учебного расчета примем z1 = 15 + N, но не менее 15 и не более 30).
- Передаточное число передачи: u = 2 + 0,5*N (например, при N=5: u = 2 + 2,5 = 4,5). Округлите до десятых.
- Шаг цепи: p = 12,7 + 2*N мм (округлите до стандартного значения из ряда: 12,7; 15,875; 19,05; 25,4; 31,75; 38,1; 44,45; 50,8 мм).
- Допустимое давление в шарнирах цепи: [p_уд] = 20 МПа (принято для учебного расчета).

Что необходимо сделать:
1. Рассчитайте число зубьев ведомой звездочки (z2) по формуле: z2 = z1 * u. Округлите до целого числа (в большую сторону). Для учебного расчета примем z2 = z1 * u (округленное до целого).
2. Уточните передаточное число с учетом принятых чисел зубьев: u_факт = z2 / z1. Округлите до сотых.
3. Рассчитайте делительные диаметры звездочек:
   - Ведущей: d1 = p / sin(180°/z1) (в мм). Округлите до целого числа.
   - Ведомой: d2 = p / sin(180°/z2) (в мм). Округлите до целого числа.
4. Примите межосевое расстояние из условия: a = (30...50) * p. Для учебного расчета примем a = 40 * p (округлите до целого числа). Запишите принятое значение a.
5. Рассчитайте число звеньев цепи (L_p) по формуле:
   L_p = 2*a/p + (z1 + z2)/2 + ( (z2 - z1) / (2*π) )^2 * p / a.
   Округлите до целого числа (в большую сторону).
6. Уточните межосевое расстояние с учетом принятого числа звеньев (a_факт) по формуле:
   a_факт = p/4 * [ (L_p - (z1 + z2)/2) + √( (L_p - (z1 + z2)/2)^2 - 8 * ( (z2 - z1) / (2*π) )^2 ) ].
   Округлите до целого числа (мм).

--------------------------------------------------
ЗАДАНИЕ 2. РАСЧЕТ СИЛ В ПЕРЕДАЧЕ
--------------------------------------------------
Исходные данные для расчета:
- Вращающий момент на валу ведущей звездочки: T1 = (N + 10) Н·м (где N — ваш номер по журналу).
- Делительный диаметр ведущей звездочки: d1 (из Задания 1).

Требуется:
1. Рассчитайте окружную силу на ведущей звездочке (F_t) по формуле: F_t = 2 * T1 / d1 (d1 — в метрах). Округлите до целого числа (Н).
2. Рассчитайте силу давления цепи на вал (F_в) по формуле: F_в = 1,15 * F_t (для цепных передач). Округлите до целого числа (Н).
3. Проверьте условие прочности цепи по допускаемому давлению в шарнирах:
   p_уд = F_t / (A_ш) ≤ [p_уд], где A_ш — площадь проекции шарнира цепи (для учебного расчета примем A_ш = 0,5 * p^2, в мм²). Рассчитайте p_уд (в МПа) и сравните с [p_уд] = 20 МПа.
4. Сделайте вывод (1–2 предложения): выполняется ли условие прочности цепи по давлению в шарнирах. Если p_уд > [p_уд], укажите, какой параметр нужно изменить (например, увеличить шаг цепи или число зубьев звездочки).

--------------------------------------------------
ЗАДАНИЕ 3. ПОСТРОЕНИЕ ЭСКИЗА ЦЕПНОЙ ПЕРЕДАЧИ
--------------------------------------------------
Требуется:
1. Начертите эскиз цепной передачи (вид сбоку) в масштабе (например, 1:2 или 1:1, если позволяет лист). На эскизе изобразите:
   - Ведущую звездочку (слева) в виде окружности с указанием делительного диаметра d1.
   - Ведомую звездочку (справа) в виде окружности с указанием делительного диаметра d2.
   - Цепь в виде двух прямых линий, соединяющих звездочки (верхняя и нижняя ветви).
   - Покажите межосевое расстояние a_факт (расстояние между центрами звездочек).
   - Укажите направление вращения ведущей звездочки (например, по часовой стрелке) и направление вращения ведомой звездочки (против часовой стрелки).
2. Подпишите все размеры на эскизе (d1, d2, a_факт).
3. Покажите на эскизе окружную силу F_t в виде стрелки, направленной по касательной к делительной окружности ведущей звездочки.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- z1 = 15 + 5 = 20.
- u = 2 + 0,5*5 = 4,5.
- z2 = 20 * 4,5 = 90.
- p = 12,7 + 2*5 = 22,7 мм → принимаем p = 25,4 мм (стандартное значение).
- u_факт = 90 / 20 = 4,5.
- d1 = 25,4 / sin(180°/20) = 25,4 / sin(9°) = 25,4 / 0,1564 ≈ 162 мм.
- d2 = 25,4 / sin(180°/90) = 25,4 / sin(2°) = 25,4 / 0,0349 ≈ 728 мм.
- a = 40 * 25,4 = 1016 мм.
- L_p = 2*1016/25,4 + (20 + 90)/2 + ( (90 - 20) / (2*3,14) )^2 * 25,4 / 1016 = 80 + 55 + (70/6,28)^2 * 25,4/1016 = 135 + (11,15)^2 * 0,025 = 135 + 124,3 * 0,025 = 135 + 3,1 ≈ 138,1 → принимаем L_p = 139 звеньев.
- a_факт = 25,4/4 * [ (139 - 55) + √( (139 - 55)^2 - 8 * (11,15)^2 ) ] = 6,35 * [ 84 + √(7056 - 994) ] = 6,35 * [ 84 + √6062 ] = 6,35 * [ 84 + 77,9 ] = 6,35 * 161,9 ≈ 1028 мм.
- T1 = 5 + 10 = 15 Н·м.
- d1 = 162 мм = 0,162 м.
- F_t = 2 * 15 / 0,162 = 30 / 0,162 ≈ 185 Н.
- F_в = 1,15 * 185 ≈ 213 Н.
- A_ш = 0,5 * 25,4^2 = 0,5 * 645,16 ≈ 322,6 мм².
- p_уд = 185 / 322,6 ≈ 0,57 МПа ≤ 20 МПа (условие выполняется).
