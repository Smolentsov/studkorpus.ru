ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 13 (часть 1)
Тема: Расчет основных геометрических характеристик зубчатых передач: геометрия зацепления

Цель работы: Формирование умений рассчитывать основные геометрические параметры прямозубой цилиндрической передачи (диаметры делительных окружностей, диаметры вершин и впадин зубьев, межосевое расстояние, передаточное число) и вычерчивать эскиз зубчатого зацепления.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, циркуль, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите эскиз зацепления (от руки, с соблюдением пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. РАСЧЕТ ГЕОМЕТРИЧЕСКИХ ПАРАМЕТРОВ ПЕРЕДАЧИ
--------------------------------------------------
Прямозубая цилиндрическая передача состоит из шестерни (ведущего колеса) и колеса (ведомого). 
Исходные данные для расчета:
- Число зубьев шестерни: z1 = 18 + N (где N — ваш номер по журналу).
- Число зубьев колеса: z2 = 40 + 2*N.
- Модуль зацепления: m = 2 + 0,1*N мм (округлите до стандартного значения из ряда: 2; 2,5; 3; 4; 5 мм. Например, при N=5 получаем m = 2,5 мм).
- Угол наклона зубьев β = 0° (прямозубая передача).

Что необходимо сделать:
1. Рассчитайте передаточное число передачи: u = z2 / z1. Округлите до сотых.
2. Рассчитайте основные геометрические параметры для шестерни:
   - Делительный диаметр: d1 = m * z1 (в мм).
   - Диаметр вершин зубьев: d_a1 = d1 + 2*m (в мм).
   - Диаметр впадин зубьев: d_f1 = d1 - 2,5*m (в мм).
   - Ширина венца шестерни: b1 = 10 * m (в мм).
3. Рассчитайте основные геометрические параметры для колеса:
   - Делительный диаметр: d2 = m * z2 (в мм).
   - Диаметр вершин зубьев: d_a2 = d2 + 2*m (в мм).
   - Диаметр впадин зубьев: d_f2 = d2 - 2,5*m (в мм).
   - Ширина венца колеса: b2 = 8 * m (в мм).
4. Рассчитайте межосевое расстояние передачи: a_w = (d1 + d2) / 2 (в мм).
5. Проверьте условие: a_w = m * (z1 + z2) / 2. Результаты должны совпасть.

--------------------------------------------------
ЗАДАНИЕ 2. ПОСТРОЕНИЕ ЭСКИЗА ЗУБЧАТОГО ЗАЦЕПЛЕНИЯ
--------------------------------------------------
Требуется:
1. Начертите эскиз прямозубой цилиндрической передачи (вид сбоку) в масштабе (например, 1:2 или 1:1, если позволяет лист). На эскизе изобразите:
   - Шестерню (слева) в виде прямоугольника с указанием делительного диаметра d1, диаметра вершин d_a1 и ширины венца b1.
   - Колесо (справа) в виде прямоугольника с указанием делительного диаметра d2, диаметра вершин d_a2 и ширины венца b2.
   - Покажите межосевое расстояние a_w (расстояние между осями валов).
   - Укажите направление вращения шестерни (например, по часовой стрелке) и направление вращения колеса (против часовой стрелки).
2. Подпишите все размеры на эскизе (d1, d_a1, b1, d2, d_a2, b2, a_w).
3. Напишите вывод (1–2 предложения): как передаточное число u влияет на размеры колеса по сравнению с шестерней (во сколько раз колесо больше шестерни).

--------------------------------------------------
ТРЕБОВАНИЯ К ОТЧЕТУ И КРИТЕРИИ ОЦЕНКИ:
--------------------------------------------------
Преподаватель проверяет работу по следующим критериям:
- Оценка «5» (отлично): Верно рассчитаны все геометрические параметры шестерни и колеса (совпадают с эталоном преподавателя), верно найдено передаточное число и межосевое расстояние. Эскиз зацепления выполнен с соблюдением пропорций, все размеры подписаны, направления вращения указаны верно. Сделан правильный вывод.
- Оценка «4» (хорошо): Все расчеты выполнены верно, но допущена одна арифметическая ошибка (например, при округлении модуля или одного из диаметров), которая не повлияла на общий результат. Эскиз выполнен, но один из размеров не подписан или нарушена пропорция (не влияющая на понимание).
- Оценка «3» (удовлетворительно): Верно найдены делительные диаметры и межосевое расстояние, но допущены ошибки в расчете диаметров вершин и впадин (перепутаны формулы). Эскиз выполнен схематично, без указания части размеров. Вывод отсутствует или сформулирован нечетко.
- Оценка «2» (неудовлетворительно): Студент не понимает геометрию зубчатой передачи, расчеты выполнены неверно (ошибки в формулах), эскиз отсутствует или выполнен хаотично. Студент не может объяснить, что такое модуль зацепления и делительный диаметр.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- z1 = 23, z2 = 50.
- m = 2 + 0,1*5 = 2,5 мм (стандартное значение).
- d1 = 2,5 * 23 = 57,5 мм.
- d_a1 = 57,5 + 2*2,5 = 62,5 мм.
- d_f1 = 57,5 - 2,5*2,5 = 51,25 мм.
- d2 = 2,5 * 50 = 125 мм.
- a_w = (57,5 + 125) / 2 = 91,25 мм.
Подставляйте свои числа и приступайте к решению. Удачи!
