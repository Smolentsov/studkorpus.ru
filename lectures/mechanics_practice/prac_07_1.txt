ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 7 (часть 1)
Тема: Решение задач на определение работы и мощности: теоретическая часть

Цель работы: Формирование умений определять работу постоянной и переменной силы, работу при вращательном движении, а также рассчитывать мощность и коэффициент полезного действия (КПД) механизмов.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите расчетную схему (от руки, с соблюдением масштаба и пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. РАБОТА ПОСТОЯННОЙ СИЛЫ ПРИ ПРЯМОЛИНЕЙНОМ ПЕРЕМЕЩЕНИИ
--------------------------------------------------
Тело движется прямолинейно под действием постоянной силы F.
Исходные данные:
- Модуль силы: F = (20 + 2*N) Н (где N — ваш номер по журналу).
- Угол между направлением силы и направлением перемещения: α = 30° + 5°*N (например, при N=5: α = 55°).
- Перемещение тела: S = 5 + 0,5*N м.

Что необходимо сделать:
1. Начертите схему: тело на горизонтальной плоскости, вектор силы F под углом α к направлению перемещения, вектор перемещения S.
2. Рассчитайте работу постоянной силы по формуле: A = F * S * cos(α). Ответ получите в Джоулях (Дж). Округлите до целого числа.
3. Определите, является ли работа положительной, отрицательной или равной нулю (если cos(α) > 0 — работа положительная, если cos(α) < 0 — отрицательная, если cos(α) = 0 — работа равна нулю).
4. Сделайте вывод (1–2 предложения): как угол между силой и перемещением влияет на величину работы (при увеличении угла от 0° до 90° работа уменьшается, при 90° равна нулю, при угле больше 90° — отрицательна).

--------------------------------------------------
ЗАДАНИЕ 2. РАБОТА РАВНОДЕЙСТВУЮЩЕЙ СИЛЫ
--------------------------------------------------
На тело действуют две силы: F1 и F2, направленные вдоль одной прямой в одну сторону.
Исходные данные:
- F1 = (10 + N) Н (где N — ваш номер по журналу).
- F2 = (15 + 2*N) Н.
- Перемещение тела: S = 4 + 0,3*N м.

Требуется:
1. Определите равнодействующую силу: R = F1 + F2 (в Н).
2. Рассчитайте работу равнодействующей силы по формуле: A_R = R * S. Ответ получите в Дж. Округлите до целого числа.
3. Проверьте: работа равнодействующей равна сумме работ каждой силы: A_R = A1 + A2, где A1 = F1 * S, A2 = F2 * S. Убедитесь, что результаты совпадают.
4. Сделайте вывод (1–2 предложения): работа равнодействующей силы равна алгебраической сумме работ составляющих сил (это свойство справедливо для любых систем сил).

--------------------------------------------------
ЗАДАНИЕ 3. РАБОТА И МОЩНОСТЬ ПРИ ВРАЩАТЕЛЬНОМ ДВИЖЕНИИ
--------------------------------------------------
Вал электродвигателя вращается с постоянной угловой скоростью ω и передает крутящий момент M_кр.
Исходные данные:
- Крутящий момент на валу: M_кр = (50 + 5*N) Н·м (где N — ваш номер по журналу).
- Частота вращения вала: n = 500 + 20*N об/мин.
- Время работы: t = 10 + N секунд.

Что необходимо сделать:
1. Переведите частоту вращения в угловую скорость по формуле: ω = π * n / 30 (в рад/с). Округлите до двух знаков.
2. Рассчитайте работу при вращательном движении по формуле: A = M_кр * φ, где φ — угол поворота за время t. φ = ω * t (в радианах). Ответ получите в Дж. Округлите до целого числа.
3. Рассчитайте мощность при вращательном движении по формуле: P = M_кр * ω. Ответ получите в Ваттах (Вт). Округлите до целого числа.
4. Проверьте: P = A / t. Результаты должны совпасть (допускается расхождение из-за округления).
5. Сделайте вывод (1–2 предложения): как мощность зависит от крутящего момента и угловой скорости (при увеличении любого из этих параметров мощность растет).

--------------------------------------------------
ЗАДАНИЕ 4. КОЭФФИЦИЕНТ ПОЛЕЗНОГО ДЕЙСТВИЯ (КПД)
--------------------------------------------------
Механизм состоит из двух последовательных передач: ременной и зубчатой.
Исходные данные:
- Мощность на входном валу: P_вх = (2 + 0,5*N) кВт (где N — ваш номер по журналу).
- КПД ременной передачи: η_рем = 0,95.
- КПД зубчатой передачи: η_зуб = 0,97.
- КПД одной пары подшипников качения: η_подш = 0,99.

Требуется:
1. Рассчитайте общий КПД механизма по формуле: η_общ = η_рем * η_зуб * η_подш² (так как две пары подшипников — на входном и выходном валах). Округлите до трех знаков после запятой.
2. Рассчитайте мощность на выходном валу по формуле: P_вых = P_вх * η_общ. Ответ получите в кВт. Округлите до двух знаков.
3. Рассчитайте потери мощности: ΔP = P_вх - P_вых. Ответ получите в кВт. Округлите до двух знаков.
4. Сделайте вывод (1–2 предложения): какие потери являются наибольшими в данном механизме (наибольшие потери в ременной передаче, так как у нее самый низкий КПД; при увеличении числа ступеней общий КПД уменьшается).

ТРЕБОВАНИЯ К ОТЧЕТУ И КРИТЕРИИ ОЦЕНКИ:
--------------------------------------------------
Преподаватель проверяет работу по следующим критериям:
- Оценка «5» (отлично): Правильно начерчены схемы, верно рассчитаны работа постоянной силы, работа равнодействующей, работа и мощность при вращательном движении, а также общий КПД и потери мощности (совпадают с эталоном преподавателя). Сделаны правильные выводы по каждому заданию.
- Оценка «4» (хорошо): Все расчеты выполнены верно, но допущена одна арифметическая ошибка (например, при переводе частоты вращения в угловую скорость или при вычислении cos(α)), которая не повлияла на общий вывод. Один из выводов сформулирован нечетко.
- Оценка «3» (удовлетворительно): Верно выполнены 2–3 задания из четырех, но допущены ошибки в расчетах (перепутаны формулы для работы или мощности). Схемы выполнены схематично. Выводы отсутствуют или сформулированы нечетко.
- Оценка «2» (неудовлетворительно): Студент не понимает, что такое работа, мощность и КПД, расчеты выполнены неверно, схемы отсутствуют. Студент не может объяснить, как работа зависит от угла между силой и перемещением.

--------------------------------------------------
Примечание для студента:
--------------------------------------------------
Если ваш номер по журналу равен, например, 5, то:
- F = 20 + 10 = 30 Н.
- α = 30° + 25° = 55°.
- S = 5 + 2,5 = 7,5 м.
- A = 30 * 7,5 * cos(55°) = 225 * 0,5736 ≈ 129 Дж.
- F1 = 10 + 5 = 15 Н.
- F2 = 15 + 10 = 25 Н.
- R = 15 + 25 = 40 Н.
- S = 4 + 1,5 = 5,5 м.
- A_R = 40 * 5,5 = 220 Дж.
- M_кр = 50 + 25 = 75 Н·м.
- n = 500 + 100 = 600 об/мин.
- ω = 3,14 * 600 / 30 = 3,14 * 20 = 62,8 рад/с.
- t = 10 + 5 = 15 с.
- φ = 62,8 * 15 = 942 рад.
- A = 75 * 942 = 70 650 Дж = 70,65 кДж.
- P = 75 * 62,8 = 4710 Вт = 4,71 кВт.
- P_вх = 2 + 2,5 = 4,5 кВт.
- η_общ = 0,95 * 0,97 * 0,99² = 0,95 * 0,97 * 0,9801 ≈ 0,903.
- P_вых = 4,5 * 0,903 = 4,06 кВт.
- ΔP = 4,5 - 4,06 = 0,44 кВт.
Подставляйте свои числа и приступайте к решению. Удачи!
