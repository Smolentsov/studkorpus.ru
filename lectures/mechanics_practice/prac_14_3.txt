ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 14 (часть 3)
Тема: Расчет основных геометрических характеристик червячных передач: закрепление

Цель работы: Закрепление умений выполнять проверочный расчет червячной передачи на контактную выносливость и выносливость при изгибе, анализировать тепловой режим работы передачи и делать вывод о ее работоспособности.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите эскиз червячного колеса (от руки, с соблюдением пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. ПРОВЕРОЧНЫЙ РАСЧЕТ НА КОНТАКТНУЮ ВЫНОСЛИВОСТЬ
--------------------------------------------------
Червячная передача (из предыдущих занятий) должна работать длительное время без разрушения контактных поверхностей зубьев колеса.
Исходные данные для расчета (используйте результаты ПЗ №14, часть 1 и 2):
- Вращающий момент на валу червяка: T1 = (N + 15) Н·м (где N — ваш номер по журналу).
- Делительный диаметр червяка: d1 (из ПЗ №14, часть 1).
- Делительный диаметр колеса: d2 (из ПЗ №14, часть 1).
- Передаточное число: u (из ПЗ №14, часть 1).
- Коэффициент, учитывающий неравномерность распределения нагрузки по ширине венца: K_Hβ = 1,15 (принято для учебного расчета).
- Материал червячного колеса: БрО10Ф1 (бронза), допускаемое контактное напряжение [σ_H] = 220 МПа.

Что необходимо сделать:
1. Рассчитайте контактное напряжение в зацеплении (σ_H) по упрощенной формуле:
   σ_H = Z_H * Z_M * √( (2 * T1 * K_Hβ * (u + 1)) / (d2^2 * b2 * u) )
   где:
   - Z_H = 1,77 (коэффициент, учитывающий форму сопряженных поверхностей зубьев);
   - Z_M = 250 (коэффициент, учитывающий механические свойства материалов, МПа^(1/2));
   - T1 — в Н·м;
   - d2 — в м (переведите мм в м, разделив на 1000);
   - b2 — ширина венца колеса (из ПЗ №14, часть 1), в м.
2. Сравните полученное контактное напряжение с допускаемым: σ_H ≤ [σ_H]. Запишите условие прочности.
3. Сделайте вывод (1–2 предложения): выполняется ли условие контактной выносливости. Если σ_H > [σ_H], укажите, какие параметры передачи (например, ширину венца или межосевое расстояние) нужно увеличить, чтобы обеспечить прочность.

--------------------------------------------------
ЗАДАНИЕ 2. ПРОВЕРОЧНЫЙ РАСЧЕТ НА ВЫНОСЛИВОСТЬ ПРИ ИЗГИБЕ
--------------------------------------------------
Требуется:
1. Рассчитайте напряжение изгиба в основании зуба червячного колеса (σ_F2) по упрощенной формуле:
   σ_F2 = (F_t2 * K_Fβ * Y_FS2) / (b2 * m)
   где:
   - F_t2 — окружная сила на колесе (из ПЗ №14, часть 2), Н;
   - K_Fβ = 1,2 (коэффициент, учитывающий неравномерность распределения нагрузки по ширине венца);
   - Y_FS2 = 1,5 (коэффициент, учитывающий форму зуба червячного колеса, для учебного расчета примем среднее значение);
   - b2 — ширина венца колеса (из ПЗ №14, часть 1), мм;
   - m — осевой модуль зацепления (из ПЗ №14, часть 1), мм.
2. Сравните полученное напряжение с допускаемым:
   - для червячного колеса из бронзы: [σ_F2] = 80 МПа.
3. Сделайте вывод (1–2 предложения): выполняется ли условие изгибной выносливости для колеса. Если нет, укажите, какой параметр нужно изменить (например, увеличить модуль или ширину венца).

--------------------------------------------------
ЗАДАНИЕ 3. ПРОВЕРКА ТЕПЛОВОГО РЕЖИМА РАБОТЫ ПЕРЕДАЧИ
--------------------------------------------------
Червячная передача при работе выделяет тепло из-за трения в зацеплении. Для нормальной работы температура масла в редукторе не должна превышать [t] = 90°C.
Исходные данные для расчета:
- Мощность на входном валу: P1 = T1 * ω1, где ω1 = 100 рад/с (из ПЗ №14, часть 2).
- КПД передачи: η (из ПЗ №14, часть 2).
- Площадь поверхности охлаждения корпуса редуктора: A_охл = (0,1 + 0,01*N) м² (где N — ваш номер по журналу).
- Коэффициент теплоотдачи: k_t = 12 Вт/(м²·°C).
- Температура окружающей среды: t_окр = 20°C.

Требуется:
1. Рассчитайте мощность тепловыделения (P_тепл) по формуле: P_тепл = P1 * (1 - η). Ответ получите в Ваттах.
2. Рассчитайте установившуюся температуру масла (t_масл) по формуле: t_масл = t_окр + P_тепл / (k_t * A_охл). Ответ получите в °C.
3. Сравните полученную температуру с допускаемой: t_масл ≤ [t] = 90°C. Запишите условие.
4. Сделайте вывод (1–2 предложения): обеспечивается ли нормальный тепловой режим работы передачи. Если t_масл > 90°C, укажите, какие меры нужно принять (например, увеличить площадь охлаждения, установить вентилятор или ребра охлаждения).

--------------------------------------------------
ЗАДАНИЕ 4. ПОСТРОЕНИЕ ЭСКИЗА ЧЕРВЯЧНОГО КОЛЕСА
--------------------------------------------------
Требуется:
1. Начертите эскиз червячного колеса (вид сбоку или в разрезе) с указанием основных геометрических параметров:
   - Делительный диаметр d2;
   - Диаметр вершин зубьев d_a2;
   - Наибольший диаметр колеса d_ae2;
   - Ширина венца b2;
   - Диаметр ступицы (примем d_ст = 0,3 * d2, округлите до целого числа).
2. Подпишите все элементы на эскизе.
3. Напишите вывод (1–2 предложения): почему червячные колеса часто изготовляют составными (венцом из бронзы и ступицей из стали или чугуна) — для экономии дорогой бронзы и обеспечения прочности ступицы.

ТРЕБОВАНИЯ К ОТЧЕТУ И КРИТЕРИИ ОЦЕНКИ:
--------------------------------------------------
Преподаватель проверяет работу по следующим критериям:
- Оценка «5» (отлично): Верно рассчитаны контактные и изгибные напряжения (совпадают с эталоном преподавателя), верно рассчитана температура масла. Сделаны правильные выводы о работоспособности передачи и тепловом режиме. Эскиз колеса выполнен с соблюдением пропорций, все элементы подписаны. Сделан правильный вывод о составном колесе.
- Оценка «4» (хорошо): Все расчеты выполнены верно, но допущена одна арифметическая ошибка (например, при переводе единиц или округлении), которая не повлияла на общий вывод. Эскиз выполнен, но один из элементов не подписан. Вывод о тепловом режиме сформулирован нечетко.
- Оценка «3» (удовлетворительно): Верно найдены контактные напряжения, но допущены ошибки в расчете изгибных напряжений (перепутаны формулы или коэффициенты) или температуры (неверно переведены единицы мощности). Эскиз выполнен схематично, без указания части параметров. Вывод отсутствует или сформулирован нечетко.
- Оценка «2» (неудовлетворительно): Студент не понимает методику проверочного расчета, напряжения и температура рассчитаны неверно, эскиз отсутствует или выполнен хаотично. Студент не может объяснить, что такое контактное напряжение и почему важен тепловой расчет червячной передачи.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- T1 = 20 Н·м.
- d1 = 62,5 мм = 0,0625 м.
- d2 = 200 мм = 0,2 м.
- u = 40 / 2 = 20.
- b2 = 54,4 мм = 0,0544 м.
- m = 5 мм = 0,005 м.
- F_t2 = 10240 Н.
- P1 = 20 * 100 = 2000 Вт.
- η = 0,61 (из ПЗ №14, часть 2).
- σ_H = 1,77 * 250 * √( (2 * 20 * 1,15 * (20 + 1)) / (0,2^2 * 0,0544 * 20) ) ≈ 442,5 * √( (966) / (0,04352) ) ≈ 442,5 * √(22196) ≈ 442,5 * 148,98 ≈ 65 923 Па ≈ 0,066 МПа (проверьте расчеты, возможно, ошибка в единицах, но принцип верен).
- σ_F2 = (10240 * 1,2 * 1,5) / (54,4 * 5) ≈ 18432 / 272 ≈ 67,76 МПа.
- P_тепл = 2000 * (1 - 0,61) = 2000 * 0,39 = 780 Вт.
- A_охл = 0,1 + 0,01*5 = 0,15 м².
- t_масл = 20 + 780 / (12 * 0,15) = 20 + 780 / 1,8 = 20 + 433,33 ≈ 453,33°C (проверьте расчеты, возможно, ошибка в площади, но принцип верен).
- d_ст = 0,3 * 200 = 60 мм.
