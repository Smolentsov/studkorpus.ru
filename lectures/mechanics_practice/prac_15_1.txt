ПРАКТИЧЕСКОЕ ЗАНЯТИЕ № 15 (часть 1)
Тема: Расчет основных характеристик передач (по вариантам): ременные передачи

Цель работы: Формирование умений рассчитывать основные параметры ременной передачи (диаметры шкивов, межосевое расстояние, длину ремня, передаточное число, силы натяжения ветвей ремня) и вычерчивать эскиз ременной передачи.

ОБОРУДОВАНИЕ И МАТЕРИАЛЫ:
Ручка, карандаш, линейка, циркуль, калькулятор, конспект лекций.

ОБЩИЕ УКАЗАНИЯ:
1. Работу выполняйте в отдельной тетради (или на двойных листах).
2. Перед началом решения перепишите условие задачи и начертите эскиз передачи (от руки, с соблюдением пропорций).
3. Все вычисления выполняйте с точностью до двух знаков после запятой.
4. В формулах используйте переменную N (где N — ваш порядковый номер в журнале группы).

--------------------------------------------------
ЗАДАНИЕ 1. РАСЧЕТ ГЕОМЕТРИЧЕСКИХ ПАРАМЕТРОВ ПЕРЕДАЧИ
--------------------------------------------------
Ременная передача состоит из ведущего шкива (малого) и ведомого шкива (большого), соединенных ремнем.
Исходные данные для расчета:
- Диаметр ведущего шкива: d1 = 80 + 2*N мм (где N — ваш номер по журналу). Округлите до стандартного значения из ряда: 80; 90; 100; 112; 125; 140; 160; 180; 200 мм.
- Передаточное число передачи: u = 2 + 0,5*N (например, при N=5: u = 2 + 2,5 = 4,5). Округлите до десятых.
- Коэффициент скольжения: ε = 0,01 (принято для учебного расчета).
- Тип ремня: клиновой, сечение А.

Что необходимо сделать:
1. Рассчитайте диаметр ведомого шкива (d2) с учетом скольжения по формуле: d2 = d1 * u * (1 - ε). Округлите до стандартного значения из ряда: 100; 112; 125; 140; 160; 180; 200; 224; 250; 280; 315; 355; 400 мм.
2. Уточните передаточное число с учетом принятого стандартного d2: u_факт = d2 / (d1 * (1 - ε)). Округлите до сотых.
3. Рассчитайте минимальное межосевое расстояние (a_min) по формуле: a_min = 0,55 * (d1 + d2) + h, где h — высота сечения ремня (для сечения А h = 8 мм). Округлите до целого числа (мм).
4. Примите межосевое расстояние из условия: a = a_min + 50 мм (округлите до целого числа). Запишите принятое значение a.
5. Рассчитайте расчетную длину ремня (L_расч) по формуле:
   L_расч = 2*a + π*(d1 + d2)/2 + (d2 - d1)^2 / (4*a).
   Округлите до целого числа (мм).
6. Округлите длину ремня до стандартного значения из ряда: 800; 900; 1000; 1120; 1250; 1400; 1600; 1800; 2000; 2240; 2500; 2800; 3150; 3550; 4000 мм. Запишите принятую длину ремня L.
7. Уточните межосевое расстояние с учетом принятой длины ремня (a_факт) по формуле:
   a_факт = 0,25 * [ (L - π*(d1 + d2)/2) + √( (L - π*(d1 + d2)/2)^2 - 8*(d2 - d1)^2 / 4 ) ].
   Округлите до целого числа (мм).

--------------------------------------------------
ЗАДАНИЕ 2. РАСЧЕТ СИЛ НАТЯЖЕНИЯ ВЕТВЕЙ РЕМНЯ
--------------------------------------------------
Исходные данные для расчета:
- Вращающий момент на валу ведущего шкива: T1 = (N + 5) Н·м (где N — ваш номер по журналу).
- Диаметр ведущего шкива: d1 (из Задания 1).
- Угол обхвата ремнем ведущего шкива: α1 = 180° - (d2 - d1)/a_факт * 57,3° (рассчитайте в градусах, округлите до целого).
- Коэффициент трения между ремнем и шкивом: f = 0,3.
- Угол клина ремня: β = 40°.

Требуется:
1. Рассчитайте окружную силу на ведущем шкиве (F_t) по формуле: F_t = 2 * T1 / d1 (d1 — в метрах). Округлите до целого числа (Н).
2. Рассчитайте силы натяжения ведущей (F1) и ведомой (F2) ветвей ремня по формулам:
   F1 = F_t * e^(f*α1/sin(β/2)) / (e^(f*α1/sin(β/2)) - 1)
   F2 = F_t / (e^(f*α1/sin(β/2)) - 1)
   где e — основание натурального логарифма (e ≈ 2,718).
   Для упрощения расчетов примите e^(f*α1/sin(β/2)) ≈ 3,0 (если угол α1 близок к 180°). Тогда:
   F1 = F_t * 3,0 / (3,0 - 1) = 1,5 * F_t.
   F2 = F_t / (3,0 - 1) = 0,5 * F_t.
   Округлите до целого числа (Н).
3. Рассчитайте силу давления на вал (F_в) по формуле: F_в = 2 * F1 * sin(α1/2). Округлите до целого числа (Н).
4. Сделайте вывод (1–2 предложения): как передаточное число u влияет на силу давления на вал (при увеличении u угол обхвата уменьшается, а сила давления на вал растет).

--------------------------------------------------
ЗАДАНИЕ 3. ПОСТРОЕНИЕ ЭСКИЗА РЕМЕННОЙ ПЕРЕДАЧИ
--------------------------------------------------
Требуется:
1. Начертите эскиз ременной передачи (вид сбоку) в масштабе (например, 1:2 или 1:1, если позволяет лист). На эскизе изобразите:
   - Ведущий шкив (слева) в виде окружности с указанием диаметра d1.
   - Ведомый шкив (справа) в виде окружности с указанием диаметра d2.
   - Ремень в виде двух прямых линий, соединяющих шкивы (верхняя и нижняя ветви).
   - Покажите межосевое расстояние a_факт (расстояние между центрами шкивов).
   - Укажите направление вращения ведущего шкива (например, по часовой стрелке) и направление вращения ведомого шкива (против часовой стрелки).
2. Подпишите все размеры на эскизе (d1, d2, a_факт).
3. Покажите на эскизе силы натяжения ветвей ремня (F1 и F2) в виде стрелок, направленных вдоль ветвей.

Примечание для студента:
Если ваш номер по журналу равен, например, 5, то:
- d1 = 80 + 2*5 = 90 мм (стандартное значение).
- u = 2 + 0,5*5 = 4,5.
- d2 = 90 * 4,5 * (1 - 0,01) = 90 * 4,5 * 0,99 = 400,95 мм → принимаем d2 = 400 мм (стандартное значение).
- u_факт = 400 / (90 * 0,99) = 400 / 89,1 ≈ 4,49.
- a_min = 0,55 * (90 + 400) + 8 = 0,55 * 490 + 8 = 269,5 + 8 = 277,5 мм → принимаем a = 277,5 + 50 = 327,5 ≈ 328 мм.
- L_расч = 2*328 + 3,14*(90 + 400)/2 + (400 - 90)^2 / (4*328) = 656 + 3,14*245 + 96100 / 1312 = 656 + 769,3 + 73,2 ≈ 1498,5 мм → принимаем L = 1400 мм (стандартное значение, ближайшее в меньшую сторону, но можно и 1600).
- a_факт = 0,25 * [ (1400 - 3,14*245) + √( (1400 - 3,14*245)^2 - 8*(400 - 90)^2 / 4 ) ] = 0,25 * [ (1400 - 769,3) + √(630,7^2 - 8*96100/4) ] = 0,25 * [ 630,7 + √(397782 - 192200) ] = 0,25 * [ 630,7 + √205582 ] = 0,25 * [ 630,7 + 453,4 ] = 0,25 * 1084,1 ≈ 271 мм.
- T1 = 5 + 5 = 10 Н·м.
- d1 = 90 мм = 0,09 м.
- F_t = 2 * 10 / 0,09 = 20 / 0,09 ≈ 222 Н.
- F1 = 1,5 * 222 = 333 Н.
- F2 = 0,5 * 222 = 111 Н.
- α1 = 180° - (400 - 90)/271 * 57,3° = 180° - 310/271 * 57,3° = 180° - 1,14 * 57,3° = 180° - 65,3° = 114,7° → принимаем 115°.
- F_в = 2 * 333 * sin(115°/2) = 666 * sin(57,5°) = 666 * 0,843 ≈ 561 Н.
